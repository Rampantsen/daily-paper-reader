## 摘要
纯视觉4D占用预测使得自动驾驶车辆能够仅从历史多视角图像预测未来3D语义场景，这对驾驶安全至关重要。尽管当前方法已取得良好性能，但输入多视角帧之间的强时空建模仍未被充分探索，这限制了这些方法在未来4D预测中的表现。为填补这一空白，我们提出了一种新颖的框架InterOCF用于4D占用预测，该框架同时建模基于3D体素的表征和多视角分割序列中的时序动态，并显式地结合2D与3D分支之间的特征交互。我们的框架包含三个核心组件：1) 3D时空模块（3DST），从历史体素状态学习体积动态以预测未来体素状态；2) 2D时空模块（2DST），采用辅助的多视角时序分割预测任务来增强时序语义动态；3) 时空交互建模模块（STIM），实现2D和3D表征之间的特征交互。在nuScenes、Lyft-Level5和nuScenes-Occupancy数据集上的实验表明，InterOCF始终优于现有基线方法。

## Abstract
Camera-only 4D occupancy forecasting enables autonomous vehicles to predict future 3D semantic scenes solely from historical multi-view images, which is critical for driving safety. Even though current methods have achieved good performance, the strong spatial-temporal modeling between the input multi-view frames is still underexplored, which limits the performance of those methods in future 4D forecasting. To address this gap, we introduce a novel framework, InterOCF, for 4D occupancy forecasting that jointly models temporal dynamics in both 3D voxel-based representations and multi-view segmentation sequences, while explicitly incorporating feature interaction between the 2D and 3D branches. Our framework incorporates three core components: 1) A 3D Spatio-Temporal (3DST) module that learns volumetric dynamics from historical voxel states to predict future voxel states; 2) A 2D Spatio-Temporal (2DST) module employing an auxiliary multi-view temporal segmentation forecasting task to enhance temporal semantic dynamics; 3) A Spatio-Temporal Interaction Modeling (STIM) module that enables feature interaction between 2D and 3D representations. Experiments on the nuScenes, Lyft-Level5, and nuScenes-Occupancy datasets show that InterOCF consistently outperforms existing baseline approaches.

### 1. 论文的核心问题与整体含义
- **任务背景**：纯视觉4D占用预测（Camera-Only 4D Occupancy Forecasting）要求仅从历史多视角图像序列，预测未来若干时刻的全场景3D语义占用（体素级类别标签），对自动驾驶安全感知至关重要。
- **现有不足**：当前主流方法（如OCFNet、OccProphet等）大多遵循“纯3D范式”——先将图像一次性提升到3D空间，再在体素上进行时序外推。这种做法丢弃了2D图像中丰富的视角依赖外观细节，稀疏体素上的时序传播易产生误差积累，且缺乏2D与3D之间的双向信息交互。
- **核心问题**：如何更有效地建模多视图历史帧之间的时空依赖，并实现2D图像语义与3D几何动态的互补融合，从而提升未来3D场景的预测精度和一致性。

### 2. 方法论
论文提出**InterOCF**框架，通过三个核心模块实现了2D‑3D交互的时空联合建模。

- **整体架构**  
  输入：\(m\) 帧历史多视图图像 \(\{I^t\}_{t=-m}^0\)  
  图像骨干网络提取多视图特征 \(\{F_{2D}^t\}_{t=-m}^0\)，特征同时送入2D分支和3D分支。

- **3D时空模块（3DST）**  
  - 利用LSS（Lift, Splat, Shoot）将2D特征提升为历史体素特征 \(\{F_{3D}^t\}_{t=-m}^0\)。  
  - **低分辨率运动建模**：用ResNet3D提取多尺度特征并下采样至一半空间分辨率，得到 \(\{\tilde{F}_{3D}^t\}\)。通过**Pre-LSTM**在大小为 \(T=m+1\) 的滑动窗口上自回归预测未来低分辨率体素状态 \(\{\tilde{F}_{3D}^t\}_{t=0}^n\)。  
  - **高分辨率细节保持**：从原始分辨率体素特征中用上下文编码器 \(\psi\) 提取高分辨率上下文 \(F_{ctx}^{enc}\)。该特征经STIM模块交互后反复制、下采样，再与低分辨率未来特征拼接，经**Post-LSTM**融合细化，最后上采样、与原始上下文拼接并卷积解码得到未来高分辨率体素预测 \(\{F_{3D}^t\}_{t=0}^n\)。  
  - 目的：在低分辨率空间扩大感受野捕捉全局运动，同时利用高分辨率上下文保留细粒度几何结构。

- **2D时空模块（2DST）**  
  - 辅助任务：预测未来多视图语义分割图，提供语义正则与时间监督。  
  - **掩码视图间注意力（MIA）**：沿宽度方向池化得到列特征 \(\tilde{F}_{2D}^{t,v}\)，每一视图仅与相邻视图做交叉注意力（利用视野重叠），得到细化列特征并残差注入。  
  - 将跨视图交互后的特征进行时序‑空间聚合，经轻量骨干网络（如ResNet‑18）产生融合特征 \(\{\bar{F}^v\}_{v=1}^V\)（送往STIM）。同时该特征通过3D转置卷积恢复未来时序维度，得到未来多视图图像特征 \(\{F_{2D}^t\}_{t=0}^n\)，再由分割头预测语义分割序列。  
  - 2D分割标签由SAM自动生成，无需人工标注。

- **时空交互建模模块（STIM）**  
  - 输入：3DST的上下文特征 \(F_{ctx}^{enc}\) 和2DST的融合多视图特征 \(\{\bar{F}^v\}\)。  
  - 操作：对 \(F_{ctx}^{enc}\) 进行两级3D下采样得到 \(\tilde{F}^{(2)}\) 和 \(\tilde{F}^{(1)}\)。从最低分辨率 \(\tilde{F}^{(2)}\) 开始，以Flatten后的2D特征做键和值、\(\tilde{F}^{(2)}\) 做查询进行交叉注意力；上采样后与 \(\tilde{F}^{(1)}\) 残差连接，再做一次交叉注意力，最后上采样回原分辨率与 \(F_{ctx}^{enc}\) 相加，获得增强后的上下文 \(\hat{F}_{ctx}^{enc}\)。  
  - 效果：由粗到细地将2D的语义外观线索逐级注入3D的几何上下文，促进互补信息融合。

### 6. 主要结论与发现
- 将2D多视图语义时序预测与3D体素动态预测相结合，并引入双向交互，可大幅提升纯视觉4D占用预测的性能，尤其在远期时间和细粒度场景中表现突出。
- 低分辨率体素建模全局运动、高分辨率上下文保留几何细节的策略，在保证计算效率的同时有效缓解了误差累积。
- 辅助的2D分割预测任务（使用SAM自动标签）提供了丰富的语义先验和时间正则化，对模型整体鲁棒性至关重要。
- InterOCF在多个基准上一致优于已有方法，展示了2D‑3D交互范式在感知预测任务上的潜力。

### 7. 优点
- **创新性交互机制**：首次在4D占用预测中显式联合建模2D和3D时空动态，并通过STIM实现多尺度双向融合，思想新颖。
- **高效的结构设计**：3DST低‑高分辨率分支分离，既捕获全局运动又保留细节；2DST的MIA巧妙利用相邻相机重叠区域，减小计算负担；整体计算效率优于多数对比方法。
- **无需人工标注**：利用SAM自动生成2D分割真值，降低标签依赖，提升方法实用性。
- **全面的实验验证**：在多个数据集、多种任务粒度下对比多种强基线，消融丰富，效率分析详尽，可视化有说服力。

### 8. 不足与局限
- **预测时长有限**：仅预测未来4帧（Lyft上0.8s、nuScenes上2s），未探索更长时域（如数秒后的场景），实际应用中仍需扩展。
- **对2D自动标注的依赖**：尽管免去了人工标注，SAM生成的分割标签可能存在噪声，对训练稳定性和最终性能的影响未深入讨论。
- **相机固有的感知局限**：纯视觉方案对恶劣天气、剧烈光照变化和遮挡场景鲁棒性未覆盖，且没有讨论与其他传感器（如激光雷达）的融合可能性。
- **消融中的组件顺序**：消融实验采用逐步添加组件的方案，未穷举所有可能的组合顺序，尽管结果趋势可信，但交互效应可能未被完全揭示。
- **泛化边界**：模型在三个主流自动驾驶数据集上表现优异，但均为结构化道路场景，对于开放环境、非标准相机布局的泛化能力须进一步验证。
