## 摘要
长时程、实时可控的运动生成对于交互式动画和人形机器人至关重要，其中智能体必须在运动过程中响应不断变化的指令和空间目标。现有的自回归扩散方法以增量方式生成运动，但有界注意力缓存限制了对久远历史的访问，而重复去噪会带来大量推理开销。我们提出 Motion Mamba 2.0，一种基于 Mamba 的根-身体扩散架构，集成了局部注意力、可续接的递归状态以及持久内容记忆（PCM），用于长时程可控运动生成。PCM 将来自 Mamba 递归状态的压缩运动历史，连同状态变化和文本条件特征，转换为可被局部注意力访问的动态更新内容槽。为实现高效推理，我们进一步开发了适配该架构的执行方案，结合 CUDA Graph 重放、融合内核和执行流简化，同时保留标准历史更新。在重定向后的 HiPHI 上的评估表明，在长达 39.52 秒的 rollout 中能够实现准确的终端控制；在 BONES Seed 和重定向后的 HumanML3D 上的短时程比较表明，该模型还保持了强大的空间控制和文本-运动匹配能力。在 RTX 4090 上，优化后的执行将完整窗口延迟中位数从 1685.35 ms 降至 276.14 ms，实现 6.138 倍的中位配对加速，同时在测试的 rollout 中保持完全相同的输出和已提交状态。此外，我们在 Unitree G1 上进行了广泛的真实世界评估，展示了顺序文本引导的动作组合、富有表现力的运动，以及通过键盘和鼠标控制的交互式移动。

## Abstract
Long-horizon, real-time controllable motion generation is essential for interactive animation and humanoid robotics, where an agent must respond to changing instructions and spatial goals while moving. Existing autoregressive diffusion methods generate motion incrementally, but bounded attention caches limit access to distant history, while repeated denoising introduces substantial inference overhead. We present Motion Mamba 2.0, a Mamba-based root-body diffusion architecture that integrates local attention, resumable recurrent states, and persistent content memory (PCM) for long-horizon controllable motion generation. PCM transforms compressed motion history from Mamba recurrent states, together with state changes and text-conditioned features, into dynamically updated content slots accessible to local attention. To enable efficient inference, we further develop an execution scheme tailored to this architecture, combining CUDA Graph replay, fused kernels, and execution-flow simplification while preserving the canonical history update. Evaluations on retargeted HiPHI demonstrate accurate terminal control over rollouts of up to 39.52 s, while short-horizon comparisons on BONES Seed and retargeted HumanML3D show that the model also retains strong spatial control and text-motion matching. On an RTX 4090, the optimized execution reduces median complete-window latency from 1685.35 to 276.14 ms, achieving a median paired speedup of 6.138$\times$ while preserving identical outputs and committed states in the tested rollouts. Moreover, we conduct extensive real-world evaluation on the Unitree G1, demonstrating sequential text-guided action composition, expressive motion, and interactive locomotion through keyboard and mouse control.

## 2. 方法论

### 2.1 总体框架
- **自回归根–身体扩散**：沿用 ARDY 的混合表示，显式根轨迹 + 因果运动编解码器压缩的身体 latent；每个 52 帧窗口独立去噪，窗口间通过记忆传递。
- **双重去噪栈**：根网络 $\mathcal{F}^r_\theta$ 先预测全局轨迹，其局部特征再条件化身体网络 $\mathcal{F}^b_\theta$；两栈参数独立、各层记忆独立。每个扩散步都先刷新根、再预测身体，使两者在采样全程耦合，而非生成后才拼接。
- **混合序列混合器**：每个 DiT 层内，注意力与 Mamba-3 处理同一份经条件调制归一化的特征，输出由可学习逐层门控组合；PCM 只增强注意力路径，不替代循环分支。

### 2.2 流式形式化
- 输出划分为 $C$ 个 token、每 token $P$ 帧；窗口 $t$ 的条件为文本 $s_t$、空间目标 $g_t$、有效性掩码 $v_t$，以及由已接受前缀构建的记忆 $\mathcal{M}_{t-1}$；条件分布按窗口分解（式 1）。
- 空间目标可落在当前窗口内或窗口外，仅作为条件输入，不要求模型提前输出中间未来运动。

### 2.3 Mamba-3 可续接递推
- 采用 SISO Mamba-3 scan：相位累积 $\phi_i$ 驱动状态输入/读出向量的旋转 $\mathcal{R}(\phi_i)$；用梯形系数 $\lambda_i$ 组合相邻状态输入；状态更新 $H_i=\alpha_i H_{i-1}+\beta_i u_{i-1}\tilde{B}_{i-1}^\top+\gamma_i u_i\tilde{B}_i^\top$，输出 $y_i=H_i\tilde{C}_i+Du_i$。

### 2.4 持久内容记忆（PCM）——核心创新
- **内容构建**：投影器 $\Pi$ 池化已接受的循环矩阵得摘要 $\bar{s}_t$，并与上一接受窗口的摘要作差得 $d_t$（分别刻画累积上下文与最新转移）。
- **文本条件写入**：文本池化嵌入经 LayerNorm + 线性层产生逐特征调制参数 $(\gamma_t,\beta_t)$，对归一化差值做调制；再与摘要、文本特征拼接，经 $f_p$ 与 LayerNorm 得到候选槽内容 $Z_t$。
- **门控写入**：写门 $w_t=\eta\,\sigma(f_w([j_t;\mathrm{vec}(P_{t-1})]))$，写速率上限 $\eta=0.25$ 限制单次更新幅度；$P_t=(1-w_t)\odot P_{t-1}+w_t\odot Z_t$。同一状态转移在不同指令下产生不同记忆更新，槽位随会话演化而非固定向量。
- **残差注意力读出**：增广键值把投影槽位插入静态 sink 之后，与基础注意力共用同一 query；输出为 $Y=A_0+\tanh(\rho_\ell)(A_P-A_0)+\sigma(\zeta_\ell)M$。**$\rho_\ell$ 初始化为 0 可精确恢复 Native 混合器输出**——这与"把槽值初始化为零"不同，因为额外 key 仍会改变注意力归一化。
- **接受式状态更新**：去噪期间所有历史为不可变快照；采样结束后，在扩散时间 0 的 canonical pass 中把 cache 追加、循环状态替换、PCM 写入在根/身体两栈**一起原子提交**；若该 pass 失败则两栈均保留旧状态。
- **有界性**：cache 仅增长到 $W$ 个窗口，循环状态与槽库定长，因此每新窗口的内存与计算不随已生成时长增长；作者同时声明这不等于任意时长下无误差。
