## 摘要
扩展视觉人形机器人移动操作技能的获取规模，需要在任务和空间配置不断扩展时减少所需的人力投入，尤其是在演示采集和任务特定训练设计方面。我们提出 SUGARv2，一个统一框架，通过交互参考合成和共享训练流程来学习多样化的视觉人形机器人移动操作技能。为了以低成本获得多样化参考，我们将可复用的任务模板适配到不同空间配置，合成协调的机器人运动与物体运动。为减少任务特定奖励设计和训练工作量，我们将基于参考的模仿作为跨任务的共同学习目标。我们首先训练特权教师来执行这些参考，然后通过教师蒸馏和强化学习训练视觉策略，并使用相同的基于参考的模仿奖励，同时采用多样化物体实例和视觉域随机化来支持视觉泛化和仿真到现实迁移。在五个仿人移动操作任务上，SUGARv2 在仿真中达到 91.0% 的平均成功率。在真实人形机器人上的部署进一步证明了全身操作的成功仿真到现实迁移。这些结果展示了该框架在学习多样化视觉人形机器人移动操作技能方面的潜力。

## Abstract
Scaling up visual humanoid loco-manipulation skill acquisition requires reducing the human effort needed as tasks and spatial configurations expand, particularly in demonstration collection and task-specific training design. We present SUGARv2, a unified framework for learning diverse visual humanoid loco-manipulation skills through interaction reference synthesis and a shared training pipeline. To obtain diverse references at low cost, we adapt reusable task templates to different spatial configurations, synthesizing coordinated robot and object motions. To reduce task-specific reward design and training effort, we use reference-based imitation as a common learning objective across tasks. We first train privileged teachers to execute these references, then train visual policies through teacher distillation and reinforcement learning with the same reference-based mimic rewards, using diverse object instances and visual domain randomization to support visual generalization and sim-to-real transfer. Across five humanoid loco-manipulation tasks, SUGARv2 achieves a mean success rate of 91.0% in simulation. Deployment on a real humanoid robot further demonstrates successful sim-to-real transfer for whole-body manipulation. These results demonstrate the framework's potential for learning diverse visual humanoid loco-manipulation skills.

- **背景**：视觉人形机器人“移动+操作”（loco-manipulation）技能需要全身协调（行走、转身、抓取、搬运同时进行），但把技能规模化扩展到多任务、多空间布局时，人力成本急剧上升。
- **两类主要成本**：
  - **示教数据采集成本**：遥操作演示采集昂贵；HumanoidMimicGen 依赖初始演示且上下身控制解耦；GRAIL 虽免遥操作，但每个空间配置都要做视频生成+动作重建，成本高且可能产生物理上不合理的交互。
  - **训练设计成本**：VIRAL、DoorMan、FetchMan 等方法需要为每个新任务单独设计奖励函数并调参。
- **核心问题**：如何在**不采集遥操作演示、不做任务专属奖励工程**的前提下，低成本地为多任务、多空间配置生成多样化交互参考，并训练出可迁移到真机的视觉全身操作策略。
- **整体含义**：论文主张“**参考合成 + 共享训练管线**”可以作为扩展人形机器人技能获取的统一范式，把“每个任务都要重新设计”的工作转化为“一次设计模板、多次实例化”的工作。

## 2. 方法论

### 2.1 核心思想
两阶段共享管线：**交互参考合成**（任务模板 → 不同空间配置下的机器人/物体轨迹）→ **策略学习**（特权教师 → 视觉学生策略），两阶段共享同一个“基于参考的模仿奖励”。

### 2.2 关键技术细节

**（1）交互参考的形式化**
- 给定空间配置 $c$（机器人初始状态、物体初始位姿、目标位置），合成管线 $G$ 生成参考 $\tau_c = \{(q_t^{robot}, q_t^{obj}, l_t)\}_{t=1}^{T}$。
- 每个时刻包含：全身机器人位姿、物体位姿、双手的预期接触标签。
- 参考是**运动学层面**的，不绑定具体物体实例，训练时可复用于同类物体。

**（2）任务模板构建**
- 用 GPT-6 Astra 生成任务级交互模板 $T$：有序的关键帧序列，每个关键帧规定全身位姿、机器人—物体/手—物体空间关系、接触标签。
- 模板捕捉跨配置共享的交互阶段（如“抓取→搬运→到达目标”），姿态仅作为适配起点。

**（3）模板实例化（逐配置适配）**
- 由物体初始位姿、目标位置、模板手—物体关系与物体对称性，生成候选手部目标；
- 在可达性与场景约束下调整机器人位置、朝向、全身姿态；
- 在可行候选中选**移动量与姿态调整最小**的关键帧；
- 由相邻关键帧间的运动需求确定时间安排；
- 用现成动作生成模型（Kimodo）并附加任务文本条件，生成连续全身运动；每个配置生成多条候选，过滤违反运动学/场景约束者，再按平滑性与少冗余运动排序；
- 物体轨迹由**交互手部运动 + 模板手—物体关系**推导，并校正使其经过关键帧指定位置；结合接触标签与关键帧时间分配接触区间。

**（4）特权教师训练**
- 教师 $\pi_T(a_t|o_t^T)$ 接收特权状态与参考轨迹，输出给**冻结的预训练全身控制器（SONIC）**的隐命令 $z_t$ 和双手开合命令 $h_t$。
- 奖励 = 跟踪项 + 交互项 + 正则项：$r_t = r_t^{track} + r_t^{int} + r_t^{reg}$。
  - 跟踪项：机器人与物体跟随参考；
  - 交互项：相对位姿与手—物体接触状态匹配参考；
  - 正则项：惩罚突变控制与不良物理行为，并**鼓励物体与目标保持在相机视野内**（为学生视觉策略服务）。
- 训练回合从“首次预期接触之前”的参考状态开始，对机器人与物体状态加随机扰动；偏离参考或进入非法物理状态时提前终止。

**（5）视觉策略学习**
- 学生 $\pi_S(a_t|o_t^S)$ 输入第一视角 RGB + 本体感知；MobileNetV4 编码图像特征，与本体感知拼接后由 MLP 输出 $(z_t, h_t)$。
- 先做教师蒸馏（DAgger 式在策略访问状态查询教师动作），损失 $\mathcal{L}_{distill} = \mathrm{MSE}(a_t^S, a_t^T)$。
- 再联合优化：$\mathcal{L}_{policy} = \mathcal{L}_{PPO}^{actor} + \lambda_{distill}\mathcal{L}_{distill}$，即**强化学习过程中保留教师监督**，用同一参考模仿奖励优化整段交互。
- 特权 critic 在蒸馏阶段预热，联合优化阶段同步更新。
- **视觉多样性**：在线渲染多样物体实例、背景、材质、光照；随机化相机位姿、图像增强、图像与本体感知加噪；两阶段均使用动力学随机化与外部扰动。同一条参考可在不同视觉外观下反复提供训练数据。

- 缺少对合成参考“物理合理性”的独立量化指标（仅用教师成功率与跟踪误差间接反映）。
- 未报告推理频率、部署硬件配置、实时性等工程指标。

## 6. 主要结论与发现

- **主结果**：五个任务仿真平均成功率 **91.0%**，比最强基线（VIRAL，39.6%）高 **51.4 个百分点**；GR00T N1.7 仅 23.4%。
- **参考质量决定上限**：使用 GRAIL 参考时，同一学习管线平均仅 28.2%（Floor-to-Table 0.6%、Same-Table 2.1%），说明参考的物理一致性对下游策略至关重要。
- **合成效率**：0.4 min/条 vs. GRAIL 36.1 min/条（约 90 倍加速）；教师成功率 98.0% vs. 62.4%；物体/机器人跟踪误差 6.6/10.0 cm vs. 9.8/13.8 cm。
- **泛化**：未见背景下 86.9%、未见物体 87.7%、两者皆未见 83.2%（原始 91.0%），性能下降但保持较高水平。
- **数据规模**：20→100 条参考提升明显，超过 100 条后收益有限甚至偶有下降，故取 100 条为性价比平衡点。
- **消融结论**：
  - 去掉教师蒸馏 → 全部任务成功率 ≈ 0%，说明从零用参考 RL 训练视觉策略在该预算下不可行；
  - 仅蒸馏不做参考 RL → 平均 41.4%，Box Carrying/Basket Transport 仅 3.6%/3.9%；
  - 蒸馏后去掉“持续”教师监督 → 平均 70.6%，低于完整方法 91.0%；
  - 即：**蒸馏提供有效初始化，参考 RL 精修性能，持续教师监督不可省**。
- **真机**：零样本迁移成功，成功率 9/10、6/10、8/10、8/10、7/10；主要失败模式是抓取失误后策略继续执行后续动作、缺乏重试恢复能力。

## 7. 优点

- **问题切分清晰**：把“数据成本”和“奖励设计成本”两个瓶颈分别用模板实例化和共享参考模仿奖励解决，逻辑闭环。
- **参考合成成本极低**：用结构化模板（关键帧 + 空间关系 + 接触标签）约束生成，避免视频生成+重建的昂贵链路，且显式保证手—物体交互一致性。
- **统一学习目标**：同一参考模仿奖励贯穿教师训练与视觉策略优化，显著降低逐任务奖励工程。
- **蒸馏与 RL 结合方式合理**：RL 阶段保留教师监督（而非纯 RL 微调），有效缓解视觉 RL 的探索困难，消融也验证了该设计的必要性。
- **奖励中嵌入“保持物体/目标在视野内”**，针对第一视角视觉策略的信息可得性做了显式设计，是有洞察力的细节。
- **视觉多样性复用运动参考**：同一运动学参考可在不同物体/背景/光照下反复渲染，数据放大几乎零边际运动成本。
- **零样本真机验证**：五个任务全部在 Unitree G1 上跑通，增强说服力。
- 诚实报告失败模式（抓取失败后无恢复），并明确列出局限与未来方向。

## 8. 不足与局限

- **任务范围有限**：仅短时程交互、简化场景；未涉及长时程任务、杂乱/遮挡环境、多物体顺序操作。
- **策略是任务专属的**：每个任务单独训练一个策略，未实现单一多任务 VLA 策略；Table 1 中“Multi-task”语义偏弱。
- **依赖外部组件**：模板由 GPT-6 Astra 生成（引入 LLM 生成质量与可复现性风险，且模板构建成本未量化）；动作生成依赖 Kimodo；底层控制依赖冻结的 SONIC 控制器，整体性能上限受这些组件制约。
- **无失败恢复机制**：抓取失误后策略继续执行，真机成功率因此受限（Floor-to-Table 仅 6/10）。
- **算力与训练细节不透明**：未报告 GPU 资源、训练时长、超参数与奖励权重，复现难度较高（关键细节置于未给出的附录）。
- **统计强度不足**：3 个种子、真机每任务 10 次试验，方差大处（±25.3）结论稳健性存疑。
- **缺少与同类合成方法的定量对比**：与 HumanoidMimicGen 等只在定性维度表比较，未在同一 benchmark 上给出成功率。
- **泛化验证范围有限**：仅验证同类物体与背景变化，未测试跨类别物体、极端光照、动态障碍、不同机器人平台。
- **潜在偏差风险**：模板与关键帧由 LLM 生成、任务与场景均为作者自建，存在任务选择与调参上的乐观偏差；GRAIL 基线在其管线下的适配可能并非最优，跨方法对比的公平性存在一定不确定性。
- **应用限制**：需要较精确的物体初始位姿与目标位置（空间配置已知），在部分可观测或需自主定位目标的真实场景中适用性受限。
