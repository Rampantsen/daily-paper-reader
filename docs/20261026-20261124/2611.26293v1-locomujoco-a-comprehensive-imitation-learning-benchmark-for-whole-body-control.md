## 摘要
LocoMuJoCo 是一个用于全身控制中模仿学习（IL）与强化学习（RL）的开源基准。该库在单一 API 下将 MuJoCo（CPU）与 MJX 及 MjWarp 后端（GPU）耦合，提供 9 种人形、3 种（肌）骨骼和 4 种四足具身，并为每个人形配备精选的原生动作捕捉数据集，还可对 AMASS 和 LAFAN1 进行重定向。模块化插件架构使观测、奖励、控制模式、地形和域随机化完全可互换，而许多 RL 和 IL 算法的紧凑 JAX 实现可提供 JIT 编译的端到端训练，配套的 loco-mujoco-real 仓库则提供仿真到现实的部署。我们介绍了设计、SMPL 到机器人以及机器人到机器人的重定向流程，并给出一个使用示例。LocoMuJoCo 以 MIT 许可证发布，地址为 https://github.com/robfiras/loco-mujoco。

## Abstract
LocoMuJoCo is an open-source benchmark for imitation learning (IL) and reinforcement learning (RL) on whole-body control. The library couples MuJoCo (CPU) with MJX and the MjWarp backend (GPU) under a single API, exposes 9 humanoid, 3 (musculo-)skeletal, and 4 quadruped embodiments, and ships a curated native motion-capture dataset for every humanoid, to which it can also retarget AMASS and LAFAN1. A modular plug-in architecture makes observations, rewards, control modes, terrains, and domain randomization fully interchangeable, while compact JAX implementations of many RL and IL algorithms provide JIT-compiled end-to-end training, and the companion loco-mujoco-real repository provides sim-to-real deployment. We describe the design, the SMPL-to-robot and robot-to-robot retargeting pipeline, and a usage example. LocoMuJoCo is released under MIT at https://github.com/robfiras/loco-mujoco.

## 1. 核心问题与研究动机

- **背景**：人形机器人硬件进步迅速，仿真到现实（sim-to-real）迁移日益可行；由于人与人的形机器人在形态上高度相似，人类动作捕捉（mocap）数据是天然且丰富的示范来源。
- **核心痛点**：全身控制 IL/RL 的评测生态高度**碎片化**——单机器人代码库、仅面向操作（manipulation）的套件、玩具级步态任务各自为政。研究者每次更换本体，都必须重写数据管线、重定向方法、仿真器封装与评测指标。
- **整体含义**：需要一个统一 API、统一数据集、统一评测协议，同时覆盖**多本体、生物力学（肌肉）模型、GPU 并行、轨迹相似度指标、真机部署**的基准平台，从而让算法比较与真机落地都可复现。

## 2. 方法论

### 2.1 总体设计思想
- **单一 API + 双/三后端**：每个环境可用串行 NumPy/MuJoCo（CPU）或向量化 JAX/MJX（GPU）执行；`use_mjwarp=True` 可切换到 MjWarp。由于 `jax.numpy` 高度对齐 NumPy，**环境逻辑只写一份**，仅后端特有操作分支，避免重复实现。
- **"一切可变项皆为插件"**：观测、奖励、控制模式、域随机化、地形、初始状态分布、终止条件均为可替换槽位。
- **无状态插件 + Flax dataclass**：每个插件的 per-env 状态显式存放于 dataclass 并随 step 传递，因此整个环境步可被 `jax.jit` / `jax.vmap` 编译，无隐藏全局状态；同一训练循环可跨机器人、跨 RL/IL 复用。

### 2.2 本体与数据
- **本体**：9 个人形（Unitree H1/H1v2/G1、Atlas、Talos、Apollo、Booster T1、ToddlerBot、Fourier GR1T2）、3 个 SMPL 派生（肌）骨骼模型（MyoSkeleton、SkeletonTorque、SkeletonMuscle，支持**身体尺寸缩放**）、4 个四足（A1/Go2、Spot、ANYmal C）。
- **数据**：HuggingFace 上的原生重定向数据集、LAFAN1、AMASS（需用户接受 SMPL 许可）。
- **控制模式**：`DefaultControl`（直驱电机/肌肉）与 `PDControl`；肌肉驱动训练流程遵循 Geiß et al. (2024)。

### 2.3 三阶段重定向流程（附录 D）
- **Stage 1：单机器人 SMPL 形状拟合（每机器人一次）**
  - 机器人摆到规范 T-pose，前向仿真得到 15 个 mimic site 世界坐标；用 Adam（1000 次迭代，lr=0.05）优化 SMPL 体型参数 β 与各向同性尺度 s，最小化 15 点对应误差：`L_shape = (1/15) Σ || p_i^robot − p_{π(i)}^smpl(θ_T, β, s) ||₂`。
  - 收敛后记录每个 site 的刚性偏移 `(R_i^{s2r}, t_i^{s2r}) ∈ SE(3)`、脚高修正 Δz、头脚高度比，序列化为 `shape_optimized.pkl`。
- **Stage 2：SMPL 动作 → 机器人轨迹**
  - 用拟合形状做 SMPL 前向运动学，再套 per-site 偏移得到每帧目标平移 `τ_{i,t}` 与目标旋转 `Q_{i,t}`（式 2、3）。
  - 将目标装入 MuJoCo mocap body，与机器人 site 以 **软约束 `mjEQ_WELD`**（非位置-only 的 `mjEQ_CONNECT`）连接；从上一帧 warm-start，积分 `N_sub=25` 个物理子步得到广义坐标 `q_t`（式 4）。软约束 + 同一物理步同时处理碰撞/关节限位/力矩限位，使轨迹**物理可行**，避免刚性 IK 常见的穿地/自穿模。
  - 可选按式 (5) 做整条轨迹的统一地面偏移；速度用中心差分恢复。
- **Stage 3：机器人到机器人迁移**
  - 先"反解"源机器人轨迹回 SMPL：去除源 site 刚性偏移（式 6、7），固定源体型 β^src，用 Adam（400 次迭代，lr=0.005，λ_p=1.0、λ_r=0.1，姿态分量加 size=3、σ=0.5 的高斯平滑）优化式 (8) 的位置+测地旋转损失，得到"合成 SMPL 片段"；再送入 Stage 2 用目标 β^tgt 生成目标轨迹。
  - **工程价值**：新增机器人只需一个配置文件 + 模型内 15 个 mimic site，无需逐条轨迹标注。

### 2.4 算法与评测
- **算法实现**（单模块 `<algo>_jax.py`，训练循环与策略更新用 `lax.scan` 融为单一 JIT 函数）：
  - 核心：PPO（默认 RL 骨干，支持多 GPU 数据并行）、GAIL、DeepMimic（配 `MimicReward`）、SuperMimic（世界模型 + 短想象 rollout + TD(λ)）。
  - 扩展：AMP、SAC、TD3、S2PG、BPTT-PPO、History-aware PPO（MLP/Transformer 观测堆叠）、DAgger 蒸馏（将 per-clip 专家压缩为多任务学生）。
- **指标**：`metrx`（JAX 原生）提供**欧氏距离、DTW、离散 Fréchet 距离**三种轨迹相似度，作用于 11 种关节/身体/site 量（实验中用 qpos、qvel、site_rpos、site_rrotvec、site_rvel 五种）。
- **真机部署**：`loco-mujoco-real` 提供 G1 与 AgiBot X2 Ultra 环境；导出 checkpoint 为 NumPy+MuJoCo 可运行的 bundle；经"逐项观测校验 → 纯 MuJoCo rollout → sim-to-sim（走机器人自身中间件，如 AimDK/ROS 2 或 Unitree SDK）"三道检查后上机；策略 50 Hz，仅用本体传感（编码器、骨盆 IMU、上一动作、参考帧），动作为关节位置目标由驱动 PD 跟踪。

## 6. 主要结果与发现

- **跨本体可训练性（实验 1）**：PPO + DeepMimic 在多数本体 × clip 组合上能收敛到较高回报与接近满回合长度，验证了统一数据管线与重定向轨迹的物理可行性；不同本体的学习难度差异明显（自由度更多、质量分布更极端、足部接触几何更复杂的本体收敛更慢），且部分 clip（单脚跳、高抬腿类）在弱驱动本体上出现回报平台或回合提前终止，说明**基准本身具备区分度**，不是"全都能刷满"的饱和任务集。
- **算法排序（实验 2）**：在完全相同的奖励、时域与超参下，PPO 在样本效率与最终回报上总体优于 SAC 与 TD3；off-policy 方法在 1000 步长时域、高维连续动作的跟踪任务上表现不稳定，支持"PPO 作为该基准默认骨干"的设计选择。
- **IL 与 RL 的可比性（实验 3）**：GAIL 仅替换奖励来源后即可在同一管线内训练，说明插件化奖励接口确实做到了"算法可插拔"；两者曲线差异反映出显式 mocap 跟踪奖励与对抗式奖励在早期探索阶段的收敛速度差别。
- **真机可行性（实验 4）**：SuperMimic 在 G1 与 X2 Ultra 上各用约 1.53×10⁸ 环境步（单卡约 50 分钟）训练出覆盖 40 条 LAFAN1 clip 的**单一多任务策略**，多数 clip 可完成较高比例的帧数，失败集中在少数高动态/长时片段；并完成 43 s BONES-SEED 舞蹈的实机演示，证明"仿真训练 → 导出 → 中间件 sim-to-sim → 上机"链路端到端可用。
- **吞吐（Table 3）**：MJX/MjWarp 在大量并行环境（≥1024）时相对 CPU MuJoCo 有数量级提升，且随并行数增加吞吐继续增长；但在**小并行数（1/8）与全自碰撞设置**下，GPU 后端优势收窄甚至可能不占优，说明"GPU 一定更快"不成立，需按并行规模与接触复杂度选后端。这是该基准给出的一个实用工程结论。
- **总体结论**：LocoMuJoCo 把"多本体 + 精选 mocap + 统一重定向 + 统一算法/指标 + 真机工具链"整合为单一可复现栈，其价值主要在于**降低跨本体比较与真机落地的边际成本**，而非提出新的 RL/IL 算法。

## 7. 局限性与批判性评估

- **基准的"冻结性"与扩展成本**：论文强调冻结数据集与统一协议以保证可比性，但这也意味着新增本体/新动作需走完整三阶段重定向流程；虽然作者声称"只需配置文件 + 15 个 mimic site"，实际仍依赖 SMPL 形状拟合质量与人工校验，规模化扩展的自动化程度未被定量评估。
- **重定向质量缺少独立评估**：Stage 2 用软约束保证物理可行性，但论文未报告重定向轨迹与原始 mocap 的定量偏差（如脚滑、接触一致性指标），也未与刚性 IK 基线做对比，因此"物理可行"的论断缺乏直接证据链。
- **指标的解释力**：DTW、离散 Fréchet、欧氏距离作用于 qpos/qvel/site 量，能刻画轨迹相似度，但对**任务语义层面的失败模式**（如摔倒、原地卡住但轨迹数值接近）区分能力有限；论文未讨论这些指标与人类感知或真机成功率的关联。
- **真机实验规模有限**：仅 2 个本体、每本体 3 seed、单次长训练，且实机演示为单片段展示，缺少多次重复的统计与失败模式分析；sim-to-real gap 的来源（观测噪声、延迟、执行器建模误差）未做分解。
- **公平性残留问题**：主实验未报告算力与方差细节，难以判断不同本体间差异是否被训练预算不均等放大；Table 1 的横向对比非定量，存在"功能清单式"比较的固有偏差。
- **算法覆盖的深度 vs. 广度**：支持 10+ 算法但多数仅在单本体、单任务族上验证，部分（AMP、BPTT-PPO、History-aware PPO、DAgger）缺少系统性结果，读者难以判断其实现成熟度。

## 8. 贡献总结与定位

- **工程贡献（主要）**：(1) 单份环境逻辑 + 双/三后端（CPU MuJoCo / MJX / MjWarp）的无状态插件架构；(2) 三阶段、可跨本体重用的 SMPL 重定向流水线与原生重定向数据集；(3) 统一的算法实现、轨迹相似度指标（`metrx`）与真机部署工具链（`loco-mujoco-real`）。
- **实证贡献**：逾千次训练运行给出的跨本体可训练性证据、PPO/SAC/TD3 与 PPO/GAIL 的受控对比、以及按并行规模划分的吞吐基准，为社区提供了可引用的经验基线。
- **定位**：这是一篇**基准/平台型论文**（benchmark & toolkit），核心价值是可复现性与互操作性，而非算法新颖性；其最直接的竞争对手是 mjlab、ProtoMotions、MimicKit 与 HumanoidBench，差异点在于"五轴全覆盖"与真机链路。
- **适用读者**：人形/四足全身控制研究者、需要快速把 mocap 数据迁移到新本体上的工程团队、以及做 sim-to-real 部署的从业者；对纯算法理论研究者价值有限。

## 9. 可复现性与开放性

- **代码与数据**：代码开源（`loco-mujoco` / `loco-mujoco-real` 双包），数据集托管于 HuggingFace，重定向结果与形状拟合产物（`shape_optimized.pkl`）随包提供，显著降低了复现门槛。
- **许可约束**：AMASS 需用户自行接受 SMPL 许可，属于**非完全开放**的数据依赖，可能限制部分机构的直接复现；LAFAN1 亦有各自许可条款。
- **可复现细节**：超参文件、seed 数、clip 列表、吞吐测量协议均有明确说明；但主实验的算力配置、多 GPU 规模、随机性控制（如是否固定硬件/驱动版本）未完整披露，属于中等程度的可复现性。
- **建议补充**：公开 715 次运行的原始日志与聚合脚本、补充重定向质量的定量指标与刚性 IK 基线、给出各算法的消融与敏感性分析，可进一步提升该基准的社区信任度与长期引用价值。
