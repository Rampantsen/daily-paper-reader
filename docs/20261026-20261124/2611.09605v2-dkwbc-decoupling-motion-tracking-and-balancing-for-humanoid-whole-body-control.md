## 摘要
人形全身控制要求机器人在重力、力矩限制、接触切换和外部扰动下跟踪多样化参考运动并保持平衡。现有基于强化学习的跟踪器通常学习同时处理运动跟踪与平衡的控制输出。然而，相似的参考姿态可能对应显著不同的动态需求，这要求统一策略在学习平衡修正的同时学习与运动相关的控制需求。这会增加学习难度，并导致控制输出出现高频波动。我们提出 DKWBC，一种融合动力学信息的全身控制框架，将显式基于模型的跟踪与学习得到的平衡残差相结合。受浮动基动力学中基于模型的项和环境力旋量对关节力矩贡献的启发，DKWBC 使用逆动力学前馈和关节 PD 反馈提供跟踪力矩，同时由残差策略学习用于平衡执行的额外关节力矩修正。通过显式考虑与运动相关的力矩需求，该结构简化了策略的学习任务。仿真和真实硬件实验表明，单一学习得到的平衡策略可在多个运动数据集上泛化，同时在支撑地面、附加负载和物理交互场景下保持准确的运动跟踪与平衡。项目页面：https://robbyant-research.github.io/DKWBC/。

## Abstract
Humanoid whole-body control requires a robot to track diverse reference motions while maintaining balance under gravity, torque limits, contact switching, and external disturbances. Existing reinforcement-learning-based trackers typically learn control outputs that jointly address motion tracking and balance. However, similar reference poses can correspond to substantially different dynamic demands, requiring a unified policy to learn motion-dependent control requirements alongside balance corrections. This can complicate learning and lead to high-frequency fluctuations in control outputs. We propose DKWBC, a dynamics-informed whole-body control framework that combines explicit model-based tracking with a learned balancing residual. Inspired by the model-based and environmental-wrench contributions to joint torques in floating-base dynamics, DKWBC uses inverse-dynamics feedforward and joint PD feedback to supply tracking torques, while a residual policy learns additional joint-torque corrections for balanced execution. By explicitly accounting for motion-dependent torque demands, this structure simplifies the policy's learning task. Experiments in simulation and on real hardware demonstrate that a single learned balancing policy generalizes across motion datasets while maintaining accurate motion tracking and balance across ground support, attached payloads, and physical interaction. ## 1. 核心问题与研究动机

- **研究背景**：人形机器人全身控制需要在重力、力矩限制、接触切换和外部扰动下，跟踪多样化参考运动并保持平衡。近年基于强化学习（RL）的跟踪器（如 SONIC、BeyondMimic、GMT 等）已显著推进该领域。
- **核心问题**：现有 RL 跟踪器通常让**单一策略同时学习运动跟踪与平衡**，输出关节位置目标，再由 PD 控制器转成力矩。但：
  - 相似的参考姿态可能对应**截然不同的速度、加速度与力矩需求**，策略必须同时学习“运动相关的控制需求”与“平衡修正”；
  - 两类目标相互竞争，易导致策略输出偏保守、降低跟踪精度，并产生**高频控制波动**。
- **整体含义**：论文主张将“运动跟踪”与“平衡执行”在**力矩层面显式解耦**——用基于模型的方法负责跟踪，用学习负责平衡，从而简化学习任务、提升数据效率与跨运动泛化能力。

## 2. 方法论

### 2.1 核心思想
受浮动基动力学方程启发，关节力矩可分解为**基于模型的项**（由机器人状态与加速度决定）与**环境力旋量项**（接触/外力，难以直接观测）。据此设计两个模块：

- **基于模型的跟踪模块**：计算名义跟踪力矩；
- **学习型残差策略**：只学习维持平衡所需的额外力矩修正。

### 2.2 动力学分解（理论依据）
浮动基动力学：
$$M(q)\dot\nu + h(q,\nu) = S^\top\tau + \sum_k J_k^\top\lambda_k$$

乘以选择矩阵 $S$ 并整理得：
$$\tau = S[M(q)\dot\nu + h(q,\nu)] - S\sum_k J_k^\top\lambda_k$$

即力矩 = 模型项 + 环境力旋量项，前者可算、后者难观测 → 分别交给跟踪模块与残差策略。

### 2.3 跟踪力矩计算（逆动力学前馈 + 关节 PD）
- **参考量求取**：参考关节速度、基座线速度用有限差分，基座角速度由 SO(3) 相对旋转得到；用三帧高斯滤波（σ=0.75 帧）平滑后微分得参考加速度 $\dot\nu_{ref}$。
- **逆动力学前馈**：用递归牛顿–欧拉算法（RNEA）在浮动基模型上计算
  $$\tau_{id} = S[\hat M(q)\dot\nu_{ref} + \hat h(q,\nu)]$$
  并拆成三项（同时作为策略观测）：
  - $\tau_{acc} = S\hat M\dot\nu_{ref}$（加速度项）
  - $\tau_{cor} = S\hat c(q,\nu)$（科氏/离心项）
  - $\tau_{grav} = S\hat g(q)$（重力项）
- **关节 PD 反馈**：
  $$\tau_{pd} = K_p^{trk}(\theta_{ref}-\theta) + K_d^{trk}(\dot\theta_{ref}-\dot\theta)$$
  增益沿用 BeyondMimic 的固定对角矩阵。文中指出 PD 反馈虽占总跟踪力矩不足 10%，但对精确执行**必不可少**（因重定向的人体动作运动学可行但动力学未必可行）。
- **最终指令**：$\tau_{trk}=\tau_{id}+\tau_{pd}$，$\tau_{cmd}=\tau_{trk}+\tau_{bal}$。

### 2.4 残差策略（平衡执行）
沿用 BeyondMimic 的 RL 模仿学习框架，但做两处关键改动：
- **跟踪力矩观测**：把 $\tau_{acc},\tau_{cor},\tau_{grav}$ 三个 n 维前馈分量加入观测，使策略能基于“已提供的跟踪力矩”来条件化其修正；上一动作特征记录 $\tau_{bal,t-1}+\tau_{id,t-1}$。
- **直接力矩动作**：策略在 50 Hz 直接输出残差关节力矩并在两次更新间保持不变（而非输出关节位置目标、由 200 Hz PD 转力矩）。理由：
  1. 切断“位置目标 → 快速关节反馈”的通路，防止策略借此做运动特定的跟踪补偿；
  2. 跟踪模块已提供名义力矩与关节误差反馈，残差策略应专注学习**跨运动共享的平衡能力**。
- **动作缩放**：$\tau_{bal,t}=s_\tau\odot a_t$，$s_{\tau,j}=0.25\,\tau_j^{max}$，即单位输出对应 25% 力矩上限。

## 6. 主要结论与发现

1. **数据效率与精度双优**：在所有 7 个训练数据规模下，DKWBC 的成功率与跟踪误差均优于重训 SONIC；4 小时起即超过官方 SONIC checkpoint；数据增至 128 h 时成功率逼近 100%。
2. **显式解耦有效**：相比耦合的 BeyondMimic，DKWBC 在 LAFAN 与两个 BONES-SEED 测试集、G/P/I 三种条件下均取得更高成功率与更低 MPJPE/MPJVE。作者推测耦合策略倾向保守输出以换取稳定，牺牲跟踪精度。
3. **跟踪模块精度极高**：无接触悬空条件下，跟踪模块单独达到 **4.45 mm MPJPE**，远优于最强 PD 基线（23.80 mm）；仅前馈误差高达 171.73 mm，说明重定向动作动力学不可行、位置反馈不可省。
4. **残差确实在补偿接触**：学习残差与仿真接触补偿力矩在幅值与时间变化上吻合。
5. **动力学观测提升泛化**：去掉任一 ID 观测分量虽在训练集 LAFAN 上变好（过拟合），但在留出集 test-repetition 上成功率下降、误差上升——说明 ID 观测提供了可迁移的平衡学习上下文。
6. **单一策略跨场景泛化**：同一平衡策略在真机上完成深蹲、负载行走、复杂动作，并在仿真中适应负载与外力扰动。

  - 从浮动基动力学方程**严格推导**出“模型项 + 环境力旋量项”的分解，为“模型跟踪 + 学习平衡”提供物理依据，而非纯工程启发。

- **可复现性**：除算力信息缺失外，BONES-SEED 的子采样方式、SONIC 的“适配后重训”具体改动、以及 11 个消融变体的完整超参配置在正文中描述较简，复现需依赖附录或代码 release。

## 9. 启发与可延伸方向

- **“模型前馈 + 学习残差”的范式可推广**：该分解不限于人形全身跟踪，可迁移至机械臂力控、四足高速运动、外骨骼助力等“名义动力学可算、环境交互难建模”的场景；关键前提是存在可靠的名义模型与可微/可算的逆动力学。
- **把力矩分量作为观测的思路值得复用**：让策略“看见”已被补偿的部分，等价于给网络提供一个**结构化的控制上下文**，这一技巧可独立于本文的分解框架用于其他分层控制架构。
- **潜在的改进点**（基于本文不足的自然延伸）：
  1. 引入在线模型辨识或扰动观测器，替代纯名义模型前馈，缓解模型误差进入 $\tau_{id}$ 的问题；
  2. 用显式接触力估计（如基于动量观测器）作为残差策略的额外监督或辅助损失，把“相关性证据”升级为“因果/定量证据”；
  3. 在真机上补充量化评估（成功率、负载谱、扰动强度谱、力矩饱和率），并做仿真–实机 gap 分析；
  4. 扩展扰动维度至躯干推挤、足底打滑与不平地形，检验残差策略的通用平衡能力边界；
  5. 对 50 Hz/200 Hz 的非对称频率做带宽分析，或引入动作平滑/低通约束以权衡响应速度与力矩抖动。

## 10. 总体评价

DKWBC 的核心贡献不在于提出新的 RL 算法，而在于**用浮动基动力学给出一个干净的问题分解**，并据此重构了观测与动作空间：跟踪交给可解析计算的逆动力学前馈 + 关节 PD，平衡交给一个只输出力矩残差的学习策略。这一设计的价值体现在三点：

1. **物理动机清晰**：分解直接来自动力学方程中“可算项”与“不可观环境力项”的划分，而非经验性模块堆叠；
2. **工程收益可测**：数据效率（4 h 即超越官方 SONIC checkpoint）、跟踪精度（无接触下 4.45 mm MPJPE）与跨分布泛化（G/P/I 三条件下优于耦合基线）均有量化支撑；
3. **分析态度诚实**：主动报告了“训练集变好但迁移变差”的消融反常、明确声明分解不能辨识真实接触力、评估不构成操作任务成功的证明。

主要短板集中在**验证的广度与深度**：真机仅定性、扰动场景单一、基线范围有限、算力与超参敏感性信息缺失，且“残差补偿接触”目前只有相关性证据。总体而言，这是一篇**方法论贡献明确、实验控制较严谨、但在实机量化与机制验证上仍有明显留白**的工作；其分解范式具备较强的可迁移性与后续研究价值。
