## 摘要
我们研究在长时域语言指令下跨多个目的地的人形机器人导航。该任务具有挑战性，因为机器人必须在连续目标之间保持进展，同时持续在受限空间中生成自然、稳定的全身运动。然而，现有方法中的任务分解本身并不能保证执行全过程中的进展，而基于路点的导航不能保证自然且忠实于路线的全身运动。我们的核心思想是将导航组织为在不同时间尺度上运行的三个互补角色：用于任务推理的 Brain、用于局部运动生成的 Cerebellum，以及用于全身执行的 Brainstem。我们在 LHNav 中实现这一思想，这是一个异步系统，利用进展和到达反馈来协调导航目标、VLA 运动 token 预测和全身控制。为了训练 Cerebellum 以生成自然且忠实于路线的运动，我们开发了一个物理基础数据引擎，该引擎改进了沿碰撞感知路线的运动参考的物理跟踪，并将生成的示范与渲染的视觉观测配对。这些设计共同使任务规划能够与连续运动并行进行，并将单目标导航扩展到连续多个目的地，同时保持自然且忠实于路线的全身运动。在仿真中，我们的导航 VLA 在单目标成功率和运动平滑性上优于 OmniNav 和 DualVLN，且碰撞和跌倒更少。仅使用在单目标示范上训练的 VLA，LHNav 在长时域导航任务上达到 75.56% 的成功率。在 Unitree G1 上的部署进一步展示了真实环境中的单目标导航和零样本长时域任务执行，包括物体被重新放置的布局。项目网站：https://robbyant-research.github.io/LHNav/。

## Abstract
We study humanoid navigation across multiple destinations under long-horizon language instructions. This task is challenging because robots must maintain progress across successive goals while continuously producing natural, stable whole-body motion through confined spaces. However, task decomposition in existing methods does not by itself ensure progress throughout execution, while waypoint-based navigation does not guarantee natural, route-faithful whole-body motion. Our key idea is to organize navigation into three complementary roles operating at different time scales: a Brain for task reasoning, a Cerebellum for local motion generation, and a Brainstem for whole-body execution. We realize this idea in LHNav, an asynchronous system that uses progress and arrival feedback to coordinate navigation goals, VLA motion-token prediction, and whole-body control. To train the Cerebellum for natural, route-faithful motion, we develop a physics-grounded data engine that improves physical tracking of motion references along collision-aware routes and pairs the resulting demonstrations with rendered visual observations. Together, these designs allow task planning to proceed alongside continuous movement and extend single-goal navigation to successive destinations with natural, route-faithful whole-body motion. In simulation, our navigation VLA outperforms OmniNav and DualVLN in single-goal success and motion smoothness, with fewer collisions and falls. Using a VLA trained only on single-goal demonstrations, LHNav achieves a 75.56% success rate on long-horizon navigation tasks. Deployment on the Unitree G1 further demonstrates single-goal navigation and zero-shot long-horizon task execution in real-world environments, including layouts with repositioned objects. Project website: https://robbyant-research.github.io/LHNav/.

# LHNav 论文深度总结

## 1. 核心问题与研究背景

- **任务定义**：研究人形机器人在**长时域自然语言指令**下的多目的地导航。例如“帮我准备午餐，然后在椅子旁等我”这类指令要求机器人自行推断需要访问的地点序列（冰箱→微波炉→餐桌→椅子），并在执行中根据任务变化（如“冷盘不需要加热”）动态修订计划。
- **两大核心挑战**：
  1. **任务进度与连续执行的耦合**：现有方法（推理监督、先思考后行动、异步分层）虽然把规划与动作放在不同时间尺度上，但“分离”本身并不保证任务连贯推进——目标切换必须反映真实执行进度，且导航不能因此中断。
  2. **路线约束与自然稳定全身运动的矛盾**：路点/轨迹/速度指令只描述“意图运动”，其全身实现被交给下游控制器，因此**无碰撞的路线并不等于无碰撞的物理执行**；在狭窄空间中长时间保持自然步态且限制位置/朝向误差仍然困难。
- **现有方法不足**：基于路点的 VLN（如 OmniNav、DualVLN）无法保证自然、忠实于路线的全身运动；而任务分解类方法缺少执行反馈闭环。
- **整体含义**：论文主张把导航组织为**三个不同时间尺度的互补角色**（Brain 任务推理 / Cerebellum 局部运动生成 / Brainstem 全身执行），并配套一个**物理落地（physics-grounded）的数据引擎**，从而把“单目标导航策略”扩展为“长时域多目标导航”，同时保持运动的自然性与路线保真度。

## 2. 方法论

### 2.1 核心思想：异步三层多速率架构

| 层 | 角色 | 实现 | 频率 |
|---|---|---|---|
| Brain | 任务推理与计划维护 | LLM Agent（GPT-6 或 Qwen3.8-27B）+ 两个工具 | 事件驱动（到达验证 ≤1 Hz） |
| Cerebellum | 局部运动生成 | 人形 VLA（GR00T N1.7 + SONIC 微调框架），输出运动 token + 辅助路点 | ~8 Hz（4 步去噪） |
| Brainstem | 全身执行 | 冻结的 SONIC 解码器 → 关节目标 → PD 控制 | 50 Hz |

三层通过**缓冲区 + 进度/到达反馈**解耦：规划、VLA 推理、全身控制并行运行，互不阻塞。

### 2.2 Brain：带工具的规划智能体

- 输入：完整指令、目标图像目录、任务分解与工具使用指南、近期观测/决策/执行反馈。
- **Tool 1（任务管理）**：维护“已完成 / 进行中 / 待执行”的显式计划，可在执行中**删除不再需要的待执行目标**，同时保留已完成访问记录与当前活动目标。
- **Tool 2（到达验证）**：独立的 Qwen VLM，以活动子任务、目标参考图、时序观测为输入，≤1 Hz 判断是否到达；诊断信息写入共享缓冲区供规划智能体读取。
- **停机握手协议**：导航停止时，运行时框架阻塞新的 VLA 请求并丢弃未完成的预测；在“到达已验证 + 运动规划耗尽 + 里程计确认根部位姿稳定”后记录完成，再由外部阶段完成事件触发下一子任务。每次只向 Cerebellum 下发简短指令（如“go to the table”）+ 目标图像。

### 2.3 Cerebellum：联合预测运动 token 与路点

- 策略形式：\((\hat{Z}_t, \hat{W}_t) = \pi_\theta(\ell_t, I_g, I_t, s_t)\)
  - \(\hat{Z}_t \in \mathbb{R}^{H\times 64}\)：运动 token 块；\(\hat{W}_t \in \mathbb{R}^{H\times 5}\)：路点；\(H=40\)。
  - 每个路点编码：观测时刻机器人坐标系下的平面位置、朝向的 sin/cos、到达指示位。
  - 注意：token 按**时间**索引，路点按**路径距离**索引，二者不逐帧对齐。
- **SDF 几何监督**：在 xy 平面上由背景可通行网格（BgMesh）与当前前景可移动障碍网格（FgMesh）预计算有符号距离场（内部为正）。对完整去噪后的路点做双线性查询，取**最小有符号间隙**（避免局部越界被平均稀释）：
  \[
  c_{\min}=\min_{i\in V} d_{\text{sdf}}(T_t\, w_i^{xy}),\quad L_{\text{sdf}}=\eta\log\!\big(1+\exp(-c_{\min}/\eta)\big)
  \]
- **总损失**：\(L = L_{\text{joint-flow}}(Z,W) + \lambda_{\text{sdf}} L_{\text{sdf}}\)
- **部署细节**：返回的 token 块跳过推理期间已执行的头部、替换未执行的尾部，**不做混合（no blending）**。

### 2.4 物理落地数据引擎（四步流程）

1. **场景与路线构建**：100 个 InteriorGS 真实感高斯场景作背景；人工标注 BgMesh；叠加可移动前景网格形成 GS+Mesh 场景；标注目标包围盒与朝向，选取包围盒外、优先正面的可接近位姿；在同一连通可通行区域内随机采样起点与朝向，用 **2D A\*** 连到接近位姿，再按间隙、平滑性、长度做路线精修。
2. **路线条件运动生成**：用 **ARDY** 以固定提示“A person is walking”合成 50 Hz 全身参考运动，加软性路径/朝向约束与端点站立姿态约束。
3. **特权跟踪（P-SONIC）**：原始 SONIC 存在全局漂移。P-SONIC 在编码器中额外输入
   \[
   p_t=\text{concat}\big(\{R_t^\top(x^{\text{ref}}_{t+\tau_j}-x_t)\}_{j=1}^{10},\ \{v^{\text{body}}_{t-j}\}_{j=9}^{0}\big)
   \]
   即**未来参考骨盆位置差 + 近期本体系线速度**；在 IsaacLab 中用 PPO 微调编码器，**冻结 FSQ 量化器与解码器**，从而保持部署时的动作接口不变。离线在 MuJoCo 中跟踪，以根倾角误差 < 25° 作为“未跌倒”标准保留 rollout，并记录**量化后的 token**（与部署时解码器实际消费的 token 一致）。
4. **执行对齐渲染与监督**：回放记录到的机器人状态渲染第一人称观测（高斯背景与 FgMesh 同相机渲染并按深度合成），每个观测监督“时序 token 块 + 按路径距离采样的当前体系路点”。

**数据引擎效果**：100 场景、184,990 条共享路线，可通行区域外路径长度占比从 **3.318% → 1.841%**，关节位置 jerk 相对“速度指令 + 前视点”引导 SONIC 降低 **44.7%**。

## 3. 实验设计

### 3.1 数据与基准

- **场景**：InteriorGS 数据集，100 个训练场景 + 20 个留出测试场景。

- **真机**：Unitree G1 + 头部前视 Orbbec Gemini335L（自研 3D 打印支架），5 个家居目的地、3 种重布局、1 个零样本长时域任务，每条件 5 次试验。

### 3.2 对比方法

- 单目标：**OmniNav**、**DualVLN**（均从公开 checkpoint 微调），以及本文 Cerebellum（从 GR00T N1.7 初始化），三者用同一数据集、同一 SONIC 执行器、同一速度设定（0.6 m/s，与 ARDY 数据采集一致）。
- 长时域：与自身变体对比（同步版、去任务管理、去到达验证；以及 Codex 版的原生 / +Harness / +Harness+tools）。

### 3.3 评价指标

- **SR0.5 / SR1.5**：无跌倒且终点距离 < 0.5 / 1.5 m 的成功率；**NE**：终点平面距离；**CR**：根轨迹落在可通行区域外的比例；**Jp**：29 个世界系关节位置 50 Hz 三阶差分均值（不平滑）；**Falls**：非碰撞跟踪跌倒次数。
- 长时域：**Task SR1.5**（目标序列匹配且每个完成位置在对应目标 1.5 m 内）、**Progress**（首次出错前完成比例）、**OSR**（是否有序进入全部目标区域）、**Time**（成功任务平均时长，含规划、导航、交接、驻留）。

### 3.4 消融设置

1. P-SONIC vs SONIC 的参考跟踪精度（100 条程序随机化 10 m 路线：缓弯/左转/右转/S 弯各 25 条）；
2. 动作表示：仅路点 / 仅运动 token / 联合预测（522 episode）；
3. 几何监督：同初始化、同数据、同预算，仅切换该项；
4. VLA 更新频率：~2 / ~5 / ~8 Hz（Brainstem 固定 50 Hz）。
