## 摘要
人形机器人可降低电气开关操作中的人员暴露风险，但安全控制仍具挑战性，因为工具必须到达与相似设备相邻的目标开关，而操作员指令不精确时可能接触到非目标开关。本研究提出一种运行时安全滤波器，在人形机器人虚拟现实遥操作过程中检查每条操作员指令。该滤波器集成了由机器人头部相机估计的场景模型，以及一个以目标为条件的控制屏障函数二次规划，在保持安全指令原样通过的同时使工具远离非目标开关。在 Unitree G1 人形机器人上的真实世界实验中，在两个站立位置各进行六轮，目标操作在全部十轮中均成功，目标保持不变且未触发非目标开关。仿真研究实现了 9/9 次安全完成，而原始遥操作为 5/9，证明了该方法用于人形机器人开关操作的可行性。

## Abstract
Humanoid robots can reduce personnel exposure in electrical switching, but safe control is challenging because the tool must reach a target switch next to similar devices, where an imprecise operator command can contact a non-target switch. This study proposes a runtime safety filter that checks each operator command during virtual-reality teleoperation of a humanoid robot. The filter integrates a scene model estimated from the robot head camera and a target-conditioned control barrier function quadratic program that keeps the tool away from the non-target switch while passing safe commands unchanged. In real-world experiments on a Unitree G1 humanoid robot, with six rounds at each of two standing positions, target operations succeed in all ten rounds with an unchanged target and no non-target actuation. A simulation study achieves 9/9 safe completions, compared with 5/9 for raw teleoperation, demonstrating the feasibility of the method for humanoid switching operations.

## 2. 方法论

### 2.1 系统总体架构

- 操作员戴 PICO 4 Ultra，经 XRoboToolkit 输出手部位姿；重定向 IK + 解耦全身控制器的上肢插值器生成名义关节指令 \(q_{\text{cmd}}\)（名义 50 Hz，限速 1.5 rad/s）。
- 行走与平衡由平衡策略负责，**仅遥操作手臂**，以把"邻柜旁的手臂运动"从行走/平衡中隔离出来；右腕装刚性 3D 打印工具。
- 在既有栈与 Unitree SDK 写指令之间插入滤波器，**不替换原栈、不需强化/模仿学习训练**。四个组件：(a) 头部 RGB-D 建场景模型；(b) 每周期 CBF-QP 滤波；(c) 边界返回与重新授权；(d) 头显操作面板。

### 2.2 场景模型（一次性、控制前构建）

- 相机采集约 900 帧 640×360@30 fps；人工框选四类区域：各柜正面、各红色手柄、柜下两块墙面。
- **平面拟合**：像素反投影为 3D 点（深度 0.1–3 m）；迭代 4 轮 SVD 最小二乘平面，法向取最小展布方向、偏移取中位数；残差阈值 \(\max(4\text{ mm}, 3\sigma)\)，\(\sigma=1.4826\,\text{MAD}\)，剔除点可在后续轮回归。墙面改用 RANSAC（160 次三点采样，固定 9.07 mm 带宽）。
- **箱体坐标系**：\(\mathbf{e}_h\) 为世界竖直在平面上的投影，\(\mathbf{e}_w=\mathbf{e}_h\times\mathbf{n}\)，\(R=[\mathbf{e}_w\ \mathbf{e}_h\ \mathbf{n}]\)。
- **柜体箱**：半尺寸固定为 (0.105, 0.13, 0.055) m（源自声明上界 0.21×0.26×0.11 m）；中心取内点左右极值中点、底面向下 1 cm、前表面向相机侧凸出 2 cm（包住手柄等突出件），向后延伸 0.11 m。
- **墙箱**：薄箱，宽高覆盖内点与选区投影，深度 \(o\pm 9.07\) mm。
- **目标条件化**：操作员选左/右开关为目标，**整个目标组件（含其柜体）从约束中移除**以保证可达；剩余 3 个箱（非目标组件 + 两墙）为约束对象 \(O_k\)。
- **绑定前检查**（研究中新增）：返回位姿处工具与非目标箱的模型距离须 ≥ 10 cm；绑定后模型不可变；仅暂停且无活动试验时可改目标，改后须重新标定。

### 2.3 环境 CBF-QP 滤波

- 决策变量 \(u\in\mathbb{R}^{14}\) 为 14 个臂关节速度；\(u_{\text{nom}}=(q_{\text{cmd}}-q_{\text{ref}})/\Delta t\)，\(\Delta t\) 为实际采样间隔（名义 0.02 s）。
- 工具头为刚性箱（8 个角点 \(p_v\)）；对每个 \(O_k\) 用精确箱-箱分离轴测试得最近外侧单位法向 \(n_k\)，\(s_k=\max_{c\in O_k} n_k^\top c\)，屏障
  \[
  h_{kv}(q)=n_k^\top p_v(q)-s_k-d,\quad d=0.05\text{ m}
  \]
  用全部 8 角可避免平行面接触掩盖其他角点旋转。
- 约束行：\(-n_k^\top J_v(q)\,u\le \gamma\max(h_{kv},0)/\Delta t\)，\(\gamma=0.35\)（50 Hz 下等效增益 ≈17.5 s⁻¹）。\(h\ge0\) 时每步最多按比例收缩；\(h<0\) 时右端为 0，只禁止继续深入、不主动推出。
- 行在编码器位姿与最后下发参考位姿各建一次 → 3 对象×8 角×2 = 48 行；关节位置/速度界 28 行；共 76 行 \(Gu\le b\)。
- 求解 \(\min_u \tfrac12\|u-u_{\text{nom}}\|^2\) s.t. \(Gu\le b\)，用 DAQP（原始/对偶容差 1e-9）；下发 \(q_{\text{ref}}+\Delta t\,u\)。**已满足全部行的指令即精确最优，原样通过**（最小干预）。

### 2.4 非阻塞调度（5 步）

1. 由当前状态与固定模型建行；几何检查失败则保持。
2. 若 \(Gu_{\text{nom}}\le b\)（容差 1e-12）直接接受，不调求解器。
3. 复用上次解的有效集 \(\mathcal{A}\)：解 \((G_\mathcal{A}G_\mathcal{A}^\top)\lambda=G_\mathcal{A}u_{\text{nom}}-b_\mathcal{A}\)，\(u=u_{\text{nom}}-G_\mathcal{A}^\top\lambda\)，需通过当前问题 KKT 检查（原始/对偶 1e-8、平稳性与互补 2e-7、条件数 ≤1e10）。
4. 若仅违反关节界，投影裁剪并按全问题 KKT 校验。
5. 否则提交单后台线程（只保留最新问题，过期结果丢弃，结果缓存后于后续周期进入第 3 步），本周期保持上一参考。
- 候选还需按步长缩放 \(\alpha\in\{1,1/2,1/4,1/8\}\) 逐级校验：满足线性行，且用下一姿态重算运动学后满足**非线性条件** \(h_{kv}(q^+)\ge h_{kv}(q)-\gamma\max(h_{kv}(q),0)\)，且不得在闭合时停在边界。全失败则"约束保持（hold）"，下周期重试同一指令，通过后无需人工干预自动继续。

### 2.5 边界返回与重新授权（闩锁）

- 触发条件：某约束对象的精确模型间隙在编码器或参考位姿处 ≤ \(d\)，且该位姿朝该对象的指令闭合速度 > 1e-7 m/s。
- 触发后脱离滤波器，经原插值器以 ≤1.5 rad/s 回到试验初始位姿（该位姿由绑定前检查保证在边界外），保持、丢弃目标、暂停，**只能经重新标定 + 显式指令恢复**——即同一未变指令无法重启向内运动。
