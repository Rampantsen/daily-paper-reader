## 摘要
在具身智能体中训练和评估空间推理需要多样化环境，这些环境既要几何保真，又要可语义查询。合成模拟器提供真实语义但牺牲真实感；基于真实世界环境重建的模拟器具有逼真外观，但默认缺乏真实语义。我们提出使用语义辐射场（SRF）作为空间推理智能体的模拟器。SRF 是一种表示方法，通过将预训练视觉模型的二维语义分割提升到三维辐射场中，统一了这些需求；该辐射场联合编码几何、外观和逐类语义身份。生成的场由真实场景的带位姿 RGB 捕获重建而成，并在单一的真实依据表示中支持新视角合成、语义查询和自由空间查询。这使得能够高效生成多样化的真实世界环境，以训练和评估空间推理模型。作为示例应用，我们概述了一个用于果园苹果抓取任务的 SRF 驱动模拟器，其中辐射场为物理引擎提供相机渲染、语义真值和占用查询。

## Abstract
Training and evaluating spatial reasoning in embodied agents requires diverse environments that are both geometrically faithful and semantically queryable. Synthetic simulators offer ground truth semantics but sacrifice realism; simulators based on reconstructions of real-world environments have realistic appearance but lack ground truth semantics by default. We propose using Semantic Radiance Fields (SRF) as simulators for spatial reasoning agents. SRFs are a representation that unifies these requirements by lifting 2D semantic segmentations from pretrained vision models into a 3D radiance field that jointly encodes geometry, appearance, and per-class semantic identity. The resulting fields are reconstructed from posed RGB captures of real scenes and support novel-view synthesis, semantic and free-space queries within a single grounded representation. This enables the efficient generation of diverse real-world environments to train and evaluate spatial reasoning models. As an example application, we outline an SRF-driven simulator for an orchard apple-reaching task, in which the radiance field supplies camera rendering, semantic ground truth, and occupancy queries to a physics engine.

# 论文总结：语义辐射场作为真实世界场景空间推理的模拟器

## 1. 论文的核心问题与整体含义

- **研究背景**：训练与评估具身智能体的空间推理能力，需要大量多样化环境；这些环境必须同时具备几何保真性和语义可查询性。
- **现有模拟器的两难**：
  - 合成程序化模拟器能提供精确语义真值与可控场景，但视觉和几何外观缺乏真实感。
  - 基于真实世界重建的模拟器外观逼真，但默认缺少可查询的语义真值。
- **核心主张**：提出 **语义辐射场（Semantic Radiance Fields, SRF）**，将预训练视觉模型的二维语义分割提升到三维辐射场中，使几何、外观和逐类语义身份在同一个表示中被联合编码。
- **整体意义**：SRF 可从真实场景的带位姿 RGB 图像重建，并支持新视角合成、语义查询和自由空间查询，从而作为一种“真实世界场景的模拟器”，用于训练和评估空间推理智能体，弥合程序化模拟器与重建式模拟器之间的鸿沟。

## 2. 论文提出的方法论

- **基础表示**：
  - 采用 Nerfacto 因子分解：密度场 \(F_\sigma: \mathbf{x} \rightarrow (\sigma, \mathbf{h})\) 输出密度和潜在特征；外观场 \(F_c: (\mathbf{h}, \mathbf{d}) \rightarrow \mathbf{c}\) 输出颜色。
  - 预期颜色通过沿射线 alpha 合成得到：\(\hat{C}(\mathbf{r}) = \sum_{k=1}^{K} \hat{T}(t_k) \alpha(\sigma(t_k)\delta_k) \mathbf{c}(t_k)\)。

- **多类语义头设计**：
  - 在共享密度骨干上附加 \(C\) 个独立二值语义头：\(F_s: \mathbf{h} \rightarrow \mathbf{s} \in \mathbb{R}^C\)。
  - 每个类别输出一个 logit，经过 sigmoid 激活，因此一个三维点可以同时属于多个类别。
  - 与 SemanticNeRF 的 softmax 互斥分类不同，该设计允许多标签/重叠语义。
  - 语义头只依赖位置，与视角无关；语义损失的梯度不回传到密度场，避免几何塌缩到类别边界。

- **语义渲染**：
  - 语义 logits 采用与颜色相同的 alpha 合成方式：
    \[
    \hat{S}(\mathbf{r}) = \sum_{k=1}^{K} \hat{T}(t_k) \alpha(\sigma(t_k)\delta_k) \mathbf{s}(t_k)
    \]

- **从二维分割提升到三维**：
  - 对每张输入图像，使用预训练模型（实验中为 SAM 3）和固定词汇文本提示生成多类二值分割 mask。
  - 语义损失使用独立二值交叉熵：
    \[
    L_{\text{sem}} = \frac{1}{|\mathcal{R}|} \sum_{\mathbf{r}\in\mathcal{R}} \text{BCE}\big(\sigma(\hat{S}(\mathbf{r})), \mathbf{y}(\mathbf{r})\big)
    \]
  - 总损失为光度损失与语义损失之和：\(L = L_{\text{photo}} + \lambda L_{\text{sem}}\)，实验中 \(\lambda = 1\)。

- **查询接口**：
  - **Render(P)**：给定相机位姿 \(P \in SE(3)\)，返回 RGB 图像、语义图和深度图。
  - **Semantic(x)**：返回任意三维点的每类概率 \(\sigma(\mathbf{s}(\mathbf{x}))\)。
  - **Occupancy(x)**：返回密度 \(\sigma(\mathbf{x})\)，用于碰撞检测。
  - 这三个操作共同支持视角采样、目标定位、碰撞检测和逐像素监督。

## 3. 实验设计

- **数据与场景**：
  - 使用 FruitNeRF 中的苹果树场景，包含 **311 张 6000×4000 像素的带位姿 RGB 图像**。
  - 直接使用提供的相机位姿，不进行位姿优化。

- **语义标注生成**：
  - 使用 SAM 3 分别以 `apple`、`branch`、`leaf` 三个文本提示查询，得到每帧每类的二值 mask。
  - 将各类 mask 合成为单张标签图（背景=0，apple=1，branch=2，leaf=3），作为 NeRF 训练的语义监督。

- **示例应用：果园苹果到达任务**：
  - 目标：机器人将末端执行器移动到目标苹果附近。
  - 物理引擎（如 MuJoCo）处理刚体动力学与机器人运动学。
  - SRF 提供 RGB 观测和语义真值图；其密度与每类概率可离线蒸馏为占用缓存（体素网格或八叉树），用于碰撞检测和奖励计算。
  - 接触信号返回物理引擎以闭环仿真。

- **对比方法与 benchmark**：
  - 论文**未进行传统 benchmark 或定量对比实验**，没有与其他模拟器或语义辐射场方法进行数值比较。
  - 实验性质属于系统原型与概念验证，而非完整评测。

## 4. 资源与算力

- **训练硬件**：单个 **NVIDIA H100 GPU**。
- **训练配置**：
  - 迭代次数：**500,000 次**。
  - 批大小：**4,096 条射线**。
  - 优化器：Adam，初始学习率 \(10^{-2}\)，指数衰减。
  - 使用混合精度训练。
  - 输入图像下采样 4 倍至 \(1500 \times 1000\) 像素。
- **训练时长**：每场景约 **4 小时**。
- **推理效率**：SRF 可离线蒸馏为占用缓存，以避免仿真过程中每步密集查询辐射场，从而提高碰撞查询效率。

## 6. 论文的主要结论与发现

- SRF 能够将真实世界重建与可查询的语义真值统一到一个表示中，适合作为空间推理智能体的训练与评估环境。
- 示例表明，单个 SRF 可以同时充当渲染器、分割真值提供者和碰撞检测器，为物理引擎闭环提供必要信号。
- 作者提出两个直接扩展方向：
  - 将同样的提升过程应用于 3D Gaussian Splatting，可降低训练时间并实现实时 rollout。
  - 引入时间轴构造动态 SRF，从空间推理扩展到时空推理。

## 7. 优点

- **表示灵活**：用独立二值语义头代替 softmax 互斥分类，允许多标签与重叠语义，更适合复杂真实场景。
- **无需手工标注**：利用预训练 SAM 3 自动获得二维语义分割，降低了数据准备成本，具备一定可扩展性。
- **接口设计清晰**：Render / Semantic / Occupancy 三个查询操作将 SRF 与物理引擎解耦，便于集成到不同模拟器。
- **计算效率考虑**：通过离线蒸馏占用缓存，避免了实时仿真中频繁查询 NeRF，提高了实用性。
- **目标明确**：准确指出程序化模拟器与重建式模拟器的不足，并给出统一的替代方案。

## 8. 不足与局限

- **实验规模极小**：只有一个场景、一个示例任务，无法证明方法在不同环境、光照、尺度下的泛化能力。
- **缺少定量评估**：未报告渲染质量、语义分割精度、碰撞检测准确性或下游策略性能等指标，难以客观判断效果。
- **依赖预训练分割模型**：SAM 3 的分割错误会传播到三维语义场，且论文未对二维分割真值的质量进行验证或清洗。
- **静态场景限制**：当前 SRF 不支持动态变化，无法处理物体移动、形变或交互后的场景更新。
- **训练成本较高**：每场景在 H100 上需约 4 小时，相比 3D Gaussian Splatting 仍缺乏实时训练与渲染能力。
- **无对比实验**：没有与 SemanticNeRF、FruitNeRF 或其他基于重建的模拟器进行直接比较，相对优势未经验证。
- **应用范围有限**：仅展示了单一机器人到达任务，对于导航、操作、问答等更广泛的空间推理任务适配性尚未验证。
