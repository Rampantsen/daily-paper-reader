## 摘要
最近的基于查询的前馈3DGS方法使用可学习查询来表示场景，每个查询聚合多视图证据并解码一组高斯。理想情况下，不同的查询应专注于场景中连贯的局部区域。然而，我们观察到从同一查询解码出的高斯经常分散在相距遥远的场景区域中，导致查询级空间一致性较弱且与场景结构对齐不佳。我们将这一行为归因于现有高斯查询的纯潜在表示。为了解决这一局限性，我们提出了LocusGS，它为每个高斯查询增加了一个由中心和支持半径组成的三维锚定状态。该锚定状态在解码器各层中逐步优化，并用于查询交互、多视图特征聚合和高斯生成的全过程。具体而言，锚点到射线的几何偏置引导每个查询关注空间相关的图像观测，而以锚点为中心的解码则将其高斯组织在局部区域内。在新视角合成基准上的实验表明，在相同高斯预算下，LocusGS相比基于查询的高斯令牌基线提高了渲染质量。进一步分析表明，学习到的锚点形成了连贯的空间布局，并导致更结构化的高斯分布，证明显式锚定状态改善了空间组织。我们的项目页面：https://leo-frank.github.io/LocusGS_viewer。

## Abstract
Recent query-based feed-forward 3DGS methods represent a scene using learnable queries, each aggregating multi-view evidence and decoding a group of Gaussians. Ideally, different queries should specialize in coherent local regions of the scene. However, we observe that Gaussians decoded from the same query often scatter across distant scene regions, resulting in weak query-level spatial coherence and poor alignment with the scene structure. We attribute this behavior to the purely latent representation of existing Gaussian queries. To address this limitation, we introduce LocusGS, which augments each Gaussian query with a 3D anchor state consisting of a center and a support radius. The anchor state is progressively refined across decoder layers and is used throughout query interaction, multi-view feature aggregation, and Gaussian generation. Specifically, an anchor-to-ray geometric bias guides each query toward spatially relevant image observations, while anchor-centered decoding organizes its Gaussians within a local region. Experiments on novel view synthesis benchmarks show that LocusGS improves rendering quality over query-based Gaussian token baselines under the same Gaussian budget. Further analysis shows that the learned anchors form coherent spatial layouts and lead to more structured Gaussian distributions, demonstrating that explicit anchor states improve the spatial organization. ## 2. 论文提出的方法论

- 核心思想：将查询从纯粹潜在嵌入升级为“空间锚定查询”，每个 token 拥有一个 3D 锚点状态 `a = (μ, r)`，其中 `μ` 为锚点中心，`r` 为支持半径。该状态在解码器各层中逐步细化，并贯穿特征聚合与高斯生成。

- 关键技术细节：
  - **锚点初始化与参数化**：锚点中心 `μ` 随机初始化于归一化场景空间；原始半径参数 `ρ` 为无约束标量，实际半径通过 `r = softplus(ρ) + ε` 获得，保证正值。
  - **锚点感知自注意力**：由锚点中心 `μ` 通过正弦位置编码和 MLP 得到位置嵌入 `p`，注入 token 特征后再进行自注意力，使 token 间交互依赖其空间位置。
  - **锚点到射线几何偏置**：在交叉注意力中，计算锚点中心 `μ` 到图像 token 对应相机射线 `ℓ` 的最短距离 `D(μ, ℓ)`，构造几何偏置：
    \[
    b = -\frac{1}{2}\left(\frac{D(\mu,\ell)}{\sigma_0 r}\right)^2
    \]
    将其加到内容注意力 logits 上，并用可学习尺度 `γ` 加权。这样查询会优先聚合射线经过锚点附近的图像特征，半径 `r` 控制偏好范围。
  - **动态锚点细化**：每个解码层后，更新后的 token 特征通过轻量头预测残差 `Δμ` 和 `Δρ`，并更新锚点：`μ ← μ + Δμ`，`ρ ← ρ + Δρ`。
  - **锚点中心化高斯解码**：最终层每个 token 预测局部偏移 `δ_i,k`，高斯中心为：
    \[
    \mu^G_{i,k} = \mu^L_i + r^L_i \delta_{i,k}
    \]
    即高斯位置由锚点中心和半径缩放的局部偏移决定，鼓励同一 token 的高斯形成紧凑局部组。
  - **多层级渲染监督**：对中间若干解码层也进行高斯解码和渲染监督，损失权重随层数递增。总损失包括重建损失（MSE + SSIM）和可见性正则（作用于高斯中心和锚点中心）。

## 6. 论文的主要结论与发现

- LocusGS 在相同高斯预算下，在两个数据集上均优于 TokenGS，并在部分指标上超过像素对齐方法。
- 学习到的锚点形成连贯的空间骨架，覆盖主要场景结构且分布自适应（细节区域锚点更密、半径更小）。
- LocusGS 显著降低 token 级高斯分散度（RE10K 均值从 5.12 降至 0.20；DL3DV 从 0.59 降至 0.04）。
- 交叉注意力更局部化且跨视图一致，表明锚点状态提供了有效的几何先验。
- 消融表明：锚点中心与半径、锚点感知自注意力、锚点到射线偏置、锚点中心化高斯解码均对性能有贡献，其中锚点中心化解码和交叉注意力偏置最重要。

## 7. 优点

- 提出显式 3D 锚点状态，直接解决查询式方法空间一致性弱的根本问题。
- 锚点状态贯穿整个解码流程：自注意力、交叉注意力、高斯解码，设计统一且合理。
- 锚点中心化解码让 token 与局部高斯组建立明确关联，提升可解释性。
- 多层级渲染监督有效提升训练稳定性和收敛速度。
- 分析充分，从紧凑度、注意力模式、锚点布局等多角度验证了方法有效性。
- 在固定预算下提升性能，保持输出高斯数量不随视图数增长。
