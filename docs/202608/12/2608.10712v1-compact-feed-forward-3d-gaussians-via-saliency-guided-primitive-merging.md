## 摘要
3D场景重建、建模和渲染与众多任务高度相关，而3D高斯泼溅已成为该领域的标准选择。其前馈变体能够从稀疏输入视图快速重建，但通常生成逐像素基元，导致表示高度冗余且效率低下。我们提出了一种结构感知的合并流程，该流程从任何前馈方法中获取逐像素基元，并将其整合为一个紧凑的、内容自适应的高斯集合，同时仅使用逐像素方法高斯数量的二十分之一即可大幅保持视觉质量。我们通过显著性图引导的自适应超像素分割，将空间一致且外观相似的高斯分组为可变大小的簇，该分割将细粒度分割分配给纹理区域，将粗粒度分割分配给均匀区域。我们通过学习到的编码器将每个簇压缩为紧凑的潜在表示，然后通过学习到的合并器基于几何重叠和特征相似性跨视图匹配并整合这些表示。随后，细节层次解码器以可控分辨率生成最终的高斯，从而在推理时实现灵活的质量-效率权衡。作为后处理模块，该流程与骨干网络无关，能够充分利用现有前馈方法的优势。与之前旨在减少基元数量的方法相比，这带来了更好且更稳健的质量，同时提供了可高效渲染的紧凑表示。

## Abstract
3D scene reconstruction, modeling, and rendering are highly relevant for numerous tasks, and 3D Gaussian splatting has become a standard choice in this context. Its feed-forward variants provide fast reconstruction from sparse input views but often produce per-pixel primitives, leading to highly redundant and thus inefficient representations. We present a structure-aware merging pipeline that takes per-pixel primitives from any feed-forward method and consolidates them into a compact, content-adaptive Gaussian set while largely retaining visual quality at just $\frac{1}{20}^\text{th}$ of the Gaussians of a per-pixel method. We group spatially coherent Gaussians of similar appearance into variable-size clusters via adaptive superpixel segmentation guided by a saliency map, which allocates fine segments to textured regions and coarse segments to homogeneous areas. We compress each cluster into a compact latent representation through a learned encoder, then match and consolidate representations across views based on geometric overlap and feature similarity via a learned merger. A level-of-detail decoder then produces the final Gaussians at a controllable resolution, enabling a flexible quality-efficiency trade-off at inference. As a post-processing module, the pipeline is backbone-agnostic, leveraging the strengths of existing feed-forward methods. This leads to better and more robust quality than achieved by previous approaches that target a reduction in primitive count, while providing a highly compact representation, that can be rendered efficiently.

## 1. 论文的核心问题与整体含义

- **研究背景**：3D高斯泼溅（3DGS）已成为3D场景重建与渲染的主流表示，但传统逐场景优化需要密集观测、计算成本高；前馈（feed-forward）方法直接从稀疏输入视图预测高斯，速度快，却普遍输出逐像素或逐体素基元，导致表示高度冗余。
- **核心问题**：冗余基元会显著增加渲染时的排序、投影和 alpha 合成成本，提升延迟与内存占用，还可能使模型过拟合输入视图并产生高频伪影。
- **整体含义**：论文旨在把任意前馈方法输出的逐像素高斯，压缩为内容自适应的紧凑高斯集合，在基本保持视觉质量的前提下，将基元数量降至约 1/20，同时提供灵活的推理期质量–效率权衡。

## 2. 论文提出的方法论

- **总体架构**：提出一种 encode–merge–decode 流水线，作为骨干无关的后处理模块，输入逐像素高斯，输出紧凑高斯集合。
- **显著性引导超像素分组**：
  - 对每个输入视图计算 Shi-Tomasi 角点响应作为显著性图。
  - 用显著性图引导 BASS（Bayesian Adaptive Superpixel Segmentation）的种子放置，使纹理丰富区域分割更细、平坦区域分割更粗。
  - 每个超像素组包含空间上连续、颜色相似的高斯。
- **Feature Gaussian 编码器**：
  - 使用 Set Transformer（MLP 编码、自注意力块 SAB、池化注意力 PMA）将每组可变数量高斯压缩为一个 Feature Gaussian。
  - Feature Gaussian 包含位置、基础颜色和潜在向量；位置由不透明度加权质心加偏移预测，避免编码器缩小几何以逃避跨视图匹配。
- **细节层次解码器**：
  - 每个 Feature Gaussian 被解码为 K 个高斯（K = 1/2/4）。
  - 通过 slot 机制生成 K 个槽 token，经过自注意力后由输出头预测高斯参数偏移。
  - 推理时可选择不同 K 头，控制输出分辨率；对 α_i < τ_a 的高斯进行剪枝。
- **跨视图匹配与合并**：
  - 对 Feature Gaussian 做 3D kNN 检索，排除同视图。
  - 匹配条件：潜在特征余弦相似度超过阈值 τ_f，且 AABB 交并比超过阈值 τ_g。
  - 取匹配图的连通分量作为合并组；无匹配者直接保留。
  - 使用与编码器同构的 Set Transformer 进行融合，零初始化残差更新第 0 个 Feature Gaussian。
- **局部细化**：
  - Refiner 基于每个 Feature Gaussian 的 kNN 邻域，通过自注意力更新参数，改善薄结构（栅栏、杆）和深度边界。
  - 残差头零初始化，保证训练稳定。
- **在线重建**：
  - 支持顺序处理视图，新视图编码为 Feature Gaussian 后与已有 FG 匹配合并，按需解码输出高斯。
- **训练目标**：
  - 主损失：MSE、SSIM、LPIPS 光度损失。
  - 教师损失：用矩匹配拟合单高斯作为早期监督，随训练衰减。
  - 解码器多样性正则化：防止 K>1 时输出重复高斯，随训练衰减。
  - 总损失为各损失加权和。
