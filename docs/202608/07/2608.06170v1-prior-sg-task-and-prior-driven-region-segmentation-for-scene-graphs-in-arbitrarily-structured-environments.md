## 摘要
层次化3D场景图是自主移动平台进行高级空间推理的一种有前景的表示。然而，现有的提取框架通常依赖纯局部视觉聚类或严格的几何启发式方法（例如由墙壁分隔的房间），这些方法在开放平面或任意结构的环境中会失效。我们提出Prior-SG，一个任务与先验驱动的框架，从根本上将场景图生成建模为一个概率对齐问题。在机器人探索过程中，它利用多尺度、开放词汇特征融合策略，将连续的RGB-D传感器流聚合到一个基于物理基础的实例图中。然后，系统通过最大后验估计推断该地图的高级功能语义，该估计由一个先验图引导——这是一个由大型语言模型动态合成的、对环境结构和任务相关词汇的逻辑期望。通过优化一个融合异构专家（视觉、几何和离散物体）与这些拓扑先验的马尔可夫随机场，系统解决了局部感知歧义。我们在多种模拟住宅数据集和大型开放平面真实环境中验证了该方法。与近期基线相比，Prior-SG实现了最先进的语义区域分割精度，在缺乏物理墙壁的情况下鲁棒地勾勒出远距离功能边界，并独特地提供了零样本本体灵活性，使机器人能够根据给定的高层级任务完全重构其空间划分。

## Abstract
Hierarchical 3D scene graphs are a promising representation for high-level spatial reasoning in autonomous mobile platforms. However, existing extraction frameworks typically rely on purely local visual clustering or strict geometric heuristics, such as wall-separated rooms, which fail in open-plan or arbitrarily-structured environments. We propose Prior-SG, a task- and prior-driven framework that casts scene graph generation fundamentally as a probabilistic alignment problem. As the robot explores, it continuously aggregates an incoming RGB-D sensor stream into a physically grounded Instance Graph utilizing a multi-scale, open-vocabulary feature fusion strategy. The system then infers the high-level functional semantics of this map through a Maximum A Posteriori (MAP) estimate, guided by a Prior Graph-a logical expectation of the environment's structure and task-relevant vocabulary synthesized dynamically by a Large Language Model. By optimizing a Markov Random Field that fuses heterogeneous experts (visual, geometric, and discrete objects) with these topological priors, the system resolves local perceptual ambiguities. We validate this approach across diverse simulated residential datasets and large, open-plan real-world environments. Prior-SG achieves state-of-the-art semantic region segmentation accuracy compared to recent baselines, robustly delineates distant functional boundaries in the absence of physical walls, and uniquely provides zero-shot ontological flexibility, enabling the robot to entirely restructure its spatial partitioning based on a given high-level task.

### 2. 方法论：核心思想与关键技术细节
- **系统架构（三阶段）**
  1. **先验图生成**（Section IV）  
     - 基于环境类型 \(E_0\) 和任务 \(T\)，用 LLM 动态生成离散结构化先验 \(G_P\)。  
     - **自上而下的状态空间截断**：LLM 列出期望的功能区域、判别性物体和代表位置。  
     - **节点内禀属性**：为物体和地点生成视觉描述符（CLIP 文本嵌入）和几何描述符（平面性、倾角等）。  
     - **概率结构边**：LLM 输出区域‑物体包含概率矩阵、区域全局存在概率 \(P(r|E_0)\) 和区域邻接转移概率矩阵。
  2. **实例图构建**（Section V）  
     - 用 Hydra 提取位置拓扑图 \(P_I\)，用 GroundingDINO + FastSAM 在 LLM 先验词汇限定下检测物体 \(O_I\)。  
     - **多尺度特征金字塔**：对每帧图像构建一系列不同尺度、重叠的滑动窗口特征（CLIP ViT‑H/14），并过滤掉物理面积过小的块。  
     - **语义集成核**：将地点查询（投影高斯体积）与金字塔中的离散特征块进行空间‑尺度加权聚合，得到单帧观察特征；通过信任加权平均进行时序融合，产生持久的视觉描述符 \(\hat{d}_{\text{vis}}\)。  
     - **几何描述符**：基于地点邻域的协方差矩阵提取局部倾角等参数。
  3. **全局推断**（Section VI）  
     - 将区域标注 \(L\) 的 MAP 估计转化为 **马尔可夫随机场（MRF）** 能量最小化：  
       \[
       E(L) = \sum_{p\in P_I} \psi_U(p, L(p)) + \sum_{(u,v)\in E_{P_I}} \psi_P(L(u), L(v))
       \]  
     - **一元势（专家乘积模型）**：  
       \[
       \psi_U(p, r) = -\sum_{k\in\{\text{vis, geo, obj, env}\}} \alpha_k(p)\log P_k(r|p)
       \]  
       其中 \(\alpha_k(p) = c_k(p)\lambda_k\)，动态置信度 \(c_k(p)\) 在观测缺失或不可靠时平滑降低贡献。  
       - 视觉专家：带 Null 类的温度 softmax 处理开放集杂波。  
       - 几何专家：用 von‑Mises 分布评估倾角对齐，置信度由邻域规模与平面性给出。  
       - 物体专家：通过 LLM 的包含先验和距离衰减最大池化将物体证据转移到地点层。  
       - 环境专家：LLM 直接给出的全局区域概率。  
     - **二元势（拓扑正则化）**：基于先验邻接概率的 Potts 模型，惩罚不合理的区域跳转。  
     - 用 **α‑β‑swap 图割** 优化非度量拓扑规则，收敛后提取连通分量并建立最终的层次区域节点 \(R_I\)。

### 6. 主要结论与发现
- Prior‑SG 在所有数据集上都取得了**最高的语义分割精度**（语义 F1 和 mIoU），尤其在真实大场景 CODa 和火车站上大幅优于 Clio。  
- 在开放平面无墙的住宅区，系统能依靠物体和拓扑先验区分功能区域（如厨房与客厅），不需物理隔断。  
- 多尺度特征金字塔避免了全局特征投射带来的语义涂抹，支持**远距离区域预测**，并能在增量探测中保持清晰边界。  
- 几何专家可作为轻量插件校正物理边界（如楼梯过渡），提高 mIoU。  
- 由 LLM 动态生成的任务先验使得系统具备**零样本本体灵活性**：同一物理空间根据不同任务提示可重构出完全不同的区域语义与拓扑划分。

### 7. 优点
- **创新性地将场景图生成形式化为概率对齐**，融合自顶向下 LLM 先验与自底向上多模态观测，摆脱对刚性几何规则的依赖。  
- **多尺度特征金字塔与集成核**有效解决了地点级视觉特征提取中的尺度失配和语义涂抹问题，支持大范围预判。  
- **专家乘积模型**优雅地处理多模态异构信号及观测缺失，通过动态置信度自动忽略不可靠专家。  
- 在广泛的环境、传感器运动模式和任务下展现出优异的泛化性和鲁棒性，并首次演示了任务驱动的空间划分能力。  
- 方法可与现有 SLAM/拓扑图框架（Hydra）无缝集成，具有扩展性（如简单地加入新的几何专家）。

### 8. 不足与局限
- **计算实时性**：目前的全局 MRF 图割每次观测更新需在全部已见地点上运行，尚未实现增量式固定计算量的在线推理，文中将其列为主要待解决问题。  
- **抽象层次单一**：推断仅限于区域层，对于城市级大规模任务需要引入更多抽象层来管理组合复杂度。  
- **静态先验**：LLM 先验在一次任务期间保持固定，不能根据新观测动态更新自己的环境模型，缺乏闭环的结构推测能力。  
- **物体检测依赖先验列表**：物体层仅检测 LLM 指定的词汇，可能遗漏开放世界中其他有用但未被列出的事物。  
- **几何专家目前较为简单**（仅平面倾角），对更复杂结构（如多层、非平面曲面）的刻画能力有限。  
- **实验评估**：部分真实数据集（如火车站）缺少与其他几何方法的直接对比，且未明确给出硬件‑能耗‑延迟的绝对指标。
