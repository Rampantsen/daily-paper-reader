## 摘要
构建统一的三维场景理解模型长期以来一直受到不同传感器模态间拓扑差异的阻碍。虽然采用专家混合（MoE）架构是一种灵活的多域三维理解方法，但我们观察到，传统的仅基于特征的 MoE 路由器在语义监督下可能未能充分表征局部采样拓扑，导致在语义一致性与几何异质性共存时专家分配变得困难。为克服这一挑战，我们提出了 STAR（空间拓扑感知路由框架）。具体而言，我们引入了一个多属性自监督预训练分支，涵盖拓扑和纹理变化，以锚定跨域结构先验。在此基础上，我们设计了一个具备两种机制的领域感知专家分支：领域-空间引导路由（DSR），从空间上下文捕获局部拓扑变化；熵控动态分配（EDA），根据路由不确定性调整激活专家的数量。这两个分支共同将稳定的跨域表示学习与自适应专家分配相结合。涵盖室内和室外场景的各种任务的广泛实验证明了 STAR 的有效性。它在 ScanNet 验证集上实现了 80.1% 的 mIoU，在 S3DIS 上实现了 77.2% 的 mIoU，相比强基线持续提升。代码可在我们的项目页面获取（https://xmw666.github.io/STAR/）。

## Abstract
Constructing a unified 3D scene understanding model has long been hindered by the topological discrepancies across sensor modalities. While applying the Mixture-of-Experts (MoE) architecture is a flexible approach for multi-domain 3D understanding, we observe that conventional feature-only MoE routers may underrepresent local sampling topology under semantic supervision, making expert allocation difficult when semantic consistency coexists with geometric heterogeneity. To overcome this challenge, we propose STAR (Spatial-Topology Aware Routing Framework). Specifically, we introduce a multi-attribute self-supervised pre-training branch, covering topological and textural variations, to anchor cross-domain structural priors. Building upon this, we design a domain-aware expert branch with two mechanisms: Domain-Spatial-Guided Routing (DSR), which captures local topological variations from spatial context, and Entropy-controlled Dynamic Allocation (EDA), which adjusts the number of activated experts according to routing uncertainty. Together, these branches combine stable cross-domain representation learning with adaptive expert allocation. Extensive experiments across various tasks, encompassing both indoor and outdoor scenes, demonstrate the effectiveness of STAR. It achieves 80.1% mIoU on the ScanNet validation set and 77.2% mIoU on S3DIS, consistently improving over strong baselines. Code is available at our project page (https://xmw666.github.io/STAR/).

## 2. 方法论

### 2.1 总体架构

STAR 采用双分支框架：

- **统一表示分支（Re）**：冻结的自监督预训练分支，为跨域结构提供稳定先验。
- **领域感知分支（Do）**：由 Domain-Spatial-Guided Routing（DSR）和 Entropy-Controlled Dynamic Allocation（EDA）组成，进行拓扑敏感的专家分配。
- 最终输出为两者之和：  
  \( f_o = f_{Do} + f_{Re} \)。

### 2.2 多属性自监督预训练分支（Re）

- 在多个数据集上做教师-学生自监督学习，教师接收原始点云，学生接收增强点云，教师权重由学生 EMA 更新。
- 针对跨域差异，设计了三类自监督扰动：
  - **颜色分布变化**：对 patch 内点随机赋予黑色。
  - **密度变化**：随机丢弃点。
  - **完整性变化**：对整块 patch 进行 mask，模拟遮挡或有限视角。
- 学生通过学习与教师的一致性（聚类损失）获得对常见域扰动的鲁棒特征。
- 预训练后，用学生网络初始化 STAR，并将 FFN 复制给 Re 和 Do 分支的所有专家；Re 分支保持冻结。

### 2.3 域-空间引导路由（DSR）

- 将输入 token 特征 \(f\) 重塑为 3D 稀疏张量，应用 3D 空间卷积，提取局部拓扑和空间位置信息，得到 \(f'\)。
- 根据数据来源得到域嵌入 \(d\)，用轻量 MLP 映射为连续向量 \(e_d\)，再广播加到 \(f'\) 上：  
  \( z = f' + e_d \)。
- 将 \(z\) 送入门控网络 \(G\)，输出路由 logits：  
  \( g = G(z) \in \mathbb{R}^{N \times K} \)，其中 \(N\) 为 token 数，\(K\) 为专家数。

### 2.4 熵控动态分配（EDA）

- 对路由 logits 做 Softmax 得到概率分布 \(p\)，计算每个 token 的 Shannon 熵 \(H\)。
- 根据熵值线性映射到激活专家数 \(k\)：熵越大激活越多专家，熵越小激活越少专家。
- 按概率降序选择 top-\(k\) 专家，选中专家的权重为其概率，其余置 0。
- 采用负载均衡损失 \(L_{balance}\) 防止专家分配失衡。
- Do 分支输出为 top-\(k\) 专家输出的加权和。

### 2.5 训练流程

- 多数据集联合训练，统一类别表示通过 CLIP-head 和 InfoNCE 损失实现。
- 联合训练损失：  
  \( L_{joint} = L_{InfoNCE} + \lambda L_{balance} \)。
- 下游任务：
  - **语义分割**：交叉熵损失。
  - **多模态检测**：基于 SpatialLM 和 Qwen2.5 的自回归坐标序列生成，使用标准交叉熵损失。
- 微调总损失：  
  \( L_{ft} = L_{task} + \lambda L_{balance} \)。
- 关键超参数：专家数 \(K=8\)，\(\lambda=0.001\)。
