## 摘要
面向社会导航的具身智能训练与验证高度依赖逼真的仿真环境，然而当前许多方法难以在真实性与可仿真性之间取得平衡。我们提出 D3D-GEN，一种新颖的世界生成系统，它将领域智能体与根植于该领域的检索增强生成（RAG）流水线相结合。该系统通过自动化领域知识收集以及逼真平面图和物体布局的合成，使用户能够快速生成领域根植、完全可交互的 3D 世界，且不依赖任何固定的 3D 模型数据库。给定领域描述提示，研究智能体会收集公开可访问的领域特定数据并构建持久化领域数据库。利用该数据库，我们的 RAG 流水线通过动态查询用户提供的语义数据库来生成合理的平面图和物体布局，该语义数据库可轻松扩展或修改。输出为完全可交互的 3D 世界，可由流行的仿真器 Isaac Sim 和 Gazebo 加载。通过我们的方法，我们已为多个常见领域（室内住宅、医院、办公室）构建数据库，并为每个领域生成了数十个不同且合理的仿真环境。我们展示了 D3D-GEN，其配备本地 Web 前端，便于快速、交互式地为机器人仿真生成世界。

## Abstract
Training and validation of Embodied AI for social navigation critically depends on realistic simulation environments, yet many current approaches fail to find a balance between realism and simulability. We propose D3D-GEN, a novel world generation system that combines a domain agent with a retrieval-augmented generation (RAG) pipeline grounded in that domain. Our system enables users to rapidly generate domain-grounded, fully interactive 3D worlds by automating both the collection of domain knowledge and the synthesis of realistic floorplans and object placements, without dependence on any fixed 3D model database. Given a domain description prompt, the research agent collects publicly accessible domain-specific data and constructs a persistent domain database. Using this database, our RAG pipeline generates plausible floorplans and object placements by dynamically querying a user-provided semantic database, which can be easily extended or modified. The output is a fully interactive 3D world loadable by the popular simulators Isaac Sim and Gazebo. With our approach, we have built databases for several common domains (indoor residential, hospital, office) and generated dozens of distinct, plausible simulation environments for each domain. We present D3D-GEN with a local web frontend that facilitates rapid, interactive world generation for robot simulation.

## 2. 论文提出的方法论

D3D-GEN 的核心思想是将**领域知识自主收集**与**检索增强生成（RAG）**相结合，把领域法规和惯例显式编码到生成流程中，而不是依赖通用先验。

### 2.1 领域数据库生成（Domain Database）
- **输入**：单个自然语言领域描述提示。
- **流程**：
  1. **领域与国家推断**：将提示分类为三元组（领域、国家、国家代码），领域限住宅、办公室、医院。
  2. **基于 Grounded Web 的调研**：对 8 个预定义主题（房间类型、尺寸范围、邻接规则、消防安全、无障碍、能效、家具设备、机器人充电/流通等）进行 `k=2` 轮 Google Search 增强的 Gemini 调用，共 16 次检索，获取公开标准、规范、指南等原始笔记及来源 URL。
  3. **语料结构化**：将原始笔记分块，按 schema 转化为类型化文档；同一 URL 的文档合并，约束按（名称、类型、值）签名去重。
  4. **数据库合成**：确定性函数将语料转为最终 JSON 数据库，包含 **Metadata** 和 **References** 两部分；每个约束具有显式来源（URL、发布者、辖区、置信度），值类型支持标量、范围、代数表达式或查找表。
- **特点**：每条约束可追溯、可引用、可复现；数据库可聚合国际规范（如 IRC 2021）、国家空间标准（如 NDSS 2015）和领域指南（如 NHS HBN 03-01）于一体。
- **机器人基础设施约束**：自动检索并注入机器人相关规则，例如充电桩最小净空半径 ≥1.2 m（180° 接近）、机器人集结区每台 2.5 m²、双向机器人交通走廊最小宽度 ≥1.8 m、机器人区与员工站之间的视线要求等，确保生成的平面图“机器人就绪”。

### 2.2 资产数据库（Asset Database）
- 自动处理的多格式 3D 模型数据集（主要为 USDZ），共 **259 个资产**：办公室 139、医院 71、住宅 49。
- 每个资产存储注释：轴对齐包围盒、材料列表、颜色调色板、人机交互（HOI）标签、面向方向、语义标签、自由文本描述。
- 所有注释拼接为单一文本嵌入，支持自然语言最近邻检索（如“可调节医院床”）。

### 2.3 世界生成流水线（Generation Pipeline）
1. **文本到场景图（Text-to-Graph）**：
   - 输入自然语言提示（如“为 60 名员工设计办公室平面图”）。
   - 生成图 `G=(V,E)`：顶点为房间，边为邻接和门关系。
   - 每个顶点包含：唯一 ID、语义房间类型、初步 8–15 个资产名、自然语言描述。
   - 额外生成**机器人操作语义标注**：如清洁区、服务区、充电缓冲区，并连接到机器人应穿行的走廊/门边；清洁机器人在开放办公区分配高覆盖清洁区，服务机器人在医院分配到护理站、病房门、供应室周边的服务区。
2. **平面图生成（Floorplan Generation）**：
   - **预处理**：根据场景图分类建筑类型，从领域数据库检索相关约束，格式化为自然语言要点注入提示。
   - **推理**：LLM 返回房间多边形和门坐标的 JSON。
   - **后处理**：用 Shapely 构造几何，从房间多边形边界差推导墙体段和门洞；为区域分配材料。
   - 输出 `WorldDescription` 对象。
3. **资产放置（Asset Population）**：
   - **检索**：多阶段匹配，结合文本相似度、房间类型兼容性和资产尺寸进行候选排序。
   - **LLM 引导的放置建议**：输入房间边界、门多边形、候选资产及目标数量；输出放置方案；随后进行硬约束验证（无重叠、边界合规、离墙偏移）；失败则执行位置搜索。
   - **输出规范化**：导出为障碍物实体，序列化为 `world.yaml`，包含区域几何、墙体材料、门尺寸/位姿、语义名称和已放置资产。
- **最终输出**：可加载于 Isaac Sim 和 Gazebo 的完全交互式 3D 世界，并带有语义标注和 ROI/POI 定位，支持导航和行为锚定。

## 6. 论文的主要结论与发现

- **定量优势**：D3D-GEN 在物体数量、物体密度、物体间距、视觉质量、VQA 准确率和 Scene Rating 上均达到最高，Layout-FID 具有竞争力。

- **领域差异**：
  - 总面积：办公室和医院比住宅扩张更显著，反映功能房间和流通需求。
  - 拓扑复杂度：医院最高（门和墙段数最多），符合走廊回路和护理工作流约束。
  - 物体密度：办公室最高（每房间 8.9 个物体），住宅较稀疏。
  - 材料多样性：医院最低，住宅和办公室更丰富。
- **机器人语义一致性**：清洁机器人在办公室被分配开放工作区的大面积清洁回路，服务机器人在医院被分配到护理站、病房门等目标服务区，减少与人类流通的交叉。
- **总体结论**：D3D-GEN 是一种可扩展、领域根植、机器人感知的 3D 世界生成方法，在结构丰富度和感知真实感方面优于现有方法，并能生成可直接用于机器人仿真的可交互环境。

## 7. 优点

- **领域根植与可追溯性**：自主从公开互联网收集法规和惯例，每个约束带来源、辖区和置信度，知识可检查、可引用、可复现。
- **机器人感知作为一等公民**：将充电、流通、机器人交通等约束显式融入生成过程，生成的平面图无需后修改即可用于机器人操作。
- **多领域可扩展性**：不依赖单一资产库或固定场景模式，已扩展至住宅、办公室、医院三个领域。
- **自然语言交互界面**：领域专家和非仿真专家均可通过自然语言描述生成世界，降低使用门槛。
- **端到端可仿真输出**：生成结果可直接加载 Isaac Sim 和 Gazebo，包含语义标注和 ROI/POI，便于后续任务规划与行为模拟。
- **对比实验全面**：覆盖平面图生成、物体放置、完整流程等不同范式的基线，并有定量和感知双重评估。
- **可复现的领域数据库构建**：数据库构建框架高度自动化，能聚合多种来源的规范，为后续研究提供可扩展的知识基础。
